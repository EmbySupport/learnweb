    Descriptive metadata

    Descriptive metadata expresses the identity, content and context of a work or resource for discovery and presentation rather than specifying how its samples are decoded.

    Descriptive metadata answers questions such as what is this, who made it, and what is it about? It supplies meaningful labels and relationships for browsing a library.

    Fields express different meanings

    For an invented film record:

    Field Example value Meaning
    Title The Station Name used for presentation
    Creator credit An invented director credit Responsibility for the work
    Description A story about a remote railway stop Account of the content
    Release year 2020 A date claim within a release context
    Identifier A named provider's record key Reference to a catalogue entity

    The title is useful wording, while the identifier refers to an entity. Treating them as the same key can merge remakes, adaptations or unrelated same-title works.

    A date also needs its intended scope. Production year, first release and a later regional release can be different facts about related material.

    A record can have several legitimate presentations

    A work may have an original title and several localized titles. An artist credit can name several contributors with a specified order or join wording. A photograph can have multiple subject keywords.

    Those distinctions should remain structured where the model supports them. Flattening every list into one comma-separated string can make it difficult to distinguish a punctuation mark inside a name from a separator between contributors.

    Descriptions can also vary by source and editorial purpose. A brief browsing summary and a detailed catalogue annotation need not be identical to describe the same work accurately.

    Personal media has a description too

    A home photo may have no public movie-provider record. Its caption, creator, capture context and subjects can still make it discoverable.

    IPTC Photo Metadata supplies relevant semantic fields for images. Their value does not depend on a provider recognizing a commercial title.

    For Emby, descriptive information shapes the displayed library and search/browsing context. Correcting it should be assessed separately from probing codecs and dimensions.
