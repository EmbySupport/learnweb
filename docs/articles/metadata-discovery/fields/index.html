    Overview: Metadata fields and localization

    Metadata fields represent values and relationships whose meaning depends on type, vocabulary and context.

    A release date, genre and cast credit answer different questions about an item. Repeated values and localization add structure beyond a single display string. This branch gives those fields their own context, so inconsistent sorting or grouping can be traced to the representation rather than only to its visible label.

    • Multi-valued metadata fields
      A multi-valued metadata field preserves several entries with an applicable order, role and identity policy instead of treating every value as one punctuation-delimited string.

    • Text and localization
      Text and localization rules connect character representation, language context and display or sorting choices.

    • Release dates
      A release date describes a particular event with territory, edition and precision context rather than one universal timestamp for a work.

    • Genre taxonomies
      A genre taxonomy organizes classification concepts and their labels or relationships, allowing consistent membership beyond matching display strings.

    • Content ratings
      A content rating is a classification within a named scheme and release/territory context, distinct from an audience or critic opinion score.

    • Cast and crew credits
      A credit relates a person or organization to a work through a role, optional character and presentation order, retaining identity beyond the printed name.
