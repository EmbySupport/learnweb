    Overview: Identification and matching

    Media identification connects a source item to the intended catalogue entry using names, identifiers and other matching evidence.

    Two works can share a title, and one work can appear under several names. Identification therefore needs enough context to distinguish the intended entry. External IDs and fingerprints supply particular evidence, while missing or conflicting metadata describe the cases where that evidence is incomplete or disagrees.

    • Media identification
      Media identification associates a local resource with the intended work or catalogue entity using content context, search evidence and scoped identifiers.

    • Title disambiguation
      Title disambiguation uses type, date, people and naming context to distinguish entities that share similar or identical display titles.

    • External identifiers
      External identifiers name entries within a particular provider or catalogue namespace.

    • Acoustic fingerprinting
      Acoustic fingerprinting derives a compact audio-content representation that a matching system can compare with known recordings, independently of filenames and byte checksums.

    • Missing metadata
      Missing metadata is a field-level absence whose cause can lie in the source, acquisition, parsing, mapping or selection rather than in one universal refresh failure.

    • Conflicting metadata
      Conflicting metadata requires comparison of entity, field meaning, scope, version and provenance before selecting or correcting the displayed value.
