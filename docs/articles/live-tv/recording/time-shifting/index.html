    Overview: Time shifting

    Time shifting separates the viewer's playback position from a continuing live source through retained media.

    The live edge advances as new programme data arrive. A buffer or recording can retain earlier data so the viewer can pause, rewind or chase a programme still being captured. These pages relate the available retained interval to the viewer's position and to the ongoing source.

    • Time-shift buffers
      A time-shift buffer retains a bounded portion of an advancing live stream so playback can pause or rewind within media that has not yet been evicted.

    • The live playback edge
      The live playback edge is the newest usable position in a particular delivery path, which remains behind acquisition and publication stages and can require additional playback margin.

    • Chase playback
      Chase playback reads an ongoing recording before capture finishes, coordinating a growing usable endpoint with the reader’s position and the recording’s final completion state.
