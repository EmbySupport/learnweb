    Cable television

    Cable television distributes services through an operator’s cable network using a defined transmission and access arrangement that a compatible source must expose to the playback system.

    Cable television is delivered through an operator’s distribution network. Its programme services can be carried in digital RF multiplexes or through other implemented operator arrangements.

    An Emby source needs a compatible path to the actual media. The presence of a cable connection does not establish that every service is exposed as an ordinary playable tuner stream.

    A cable carrier and its services differ

    A digital RF channel can contain several encoded programme services. Frequency and modulation locate the carrier; service information identifies which programme is requested.

    Description Example role
    RF frequency/modulation Tuner acquisition
    Multiplex/transport identity Recovered carrier’s data context
    Service/programme identifier Selected media within that context
    Operator channel number The lineup’s viewer-facing label
    Guide channel identifier Programme-description association

    Changing a service’s viewer-facing number need not change its frequency or media components.

    Modulation does not describe access permission

    QAM describes a modulation arrangement. Clear QAM describes relevant cable services that are unencrypted, under a compatible reception path.

    A cable network can contain protected services as well as clear ones. Recovering their RF data does not establish a supported decryption and playback route.

    Encrypted channels separates acquisition, entitlement and the implemented protection path. A subscription relationship and a generic QAM tuner are not interchangeable pieces of that route.

    DVB-C is another specifically defined cable transmission system; the service’s actual coding and access properties remain additional information.

    A box output is already another representation

    An operator box can receive and process a service, then emit a prepared HDMI presentation. That output is different from the encoded service feed exposed by a tuner/backend.

    The box’s video output capability does not prove that its original service can be acquired through an unrelated server interface. Likewise, an HDMI display signal does not carry the original movie container in the ordinary presentation path.

    HDMI video transport develops that later representation.

    Emby needs the source and its identity

    A supported cable tuner or backend can supply the channel inventory and media acquisition interface. Guide mapping then associates those source channels with programme descriptions.

    Availability is specific to the operator, region, source hardware and implemented access route. A manufacturer’s Clear QAM example is not a declaration that every cable provider currently sends those services.
