    Overview: Electronic programme guides

    Electronic programme guides connect channel identity with scheduled events, source data and time conventions.

    A guide entry needs the right channel and the right time interpretation before it can support a recording decision. Programme IDs and schedule changes add further relationships as the listing evolves. This branch explains those mappings so a correct-looking title is not mistaken for a fully matched recording event.

    • What is an EPG?
      An electronic programme guide associates stations and time intervals with programme descriptions, supplying the schedule information used for browsing and programme-based recording.

    • Guide sources and formats
      Guide sources and formats encode programme schedules and supporting service information through different conventions.

    • Channel mapping
      Channel mapping associates a selectable source service with the corresponding guide station, preserving station and provider context when names or numbers are ambiguous.

    • Programme identifiers
      Programme identifiers distinguish series, episodes and scheduled airings within a provider or broadcast context, enabling reliable joins without treating titles or local IDs as universal keys.

    • Guide time zones
      Guide time zones determine how supplied date/time values become absolute instants and local display times, including repeated or missing clock times around daylight-saving changes.

    • Programme schedule changes
      Programme schedule changes revise the station, time or content associated with an airing, requiring the loaded guide and recording plan to be evaluated separately.
