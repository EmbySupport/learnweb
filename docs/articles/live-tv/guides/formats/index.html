    Overview: Guide sources and formats

    Guide sources and formats encode programme schedules and supporting service information through different conventions.

    XMLTV, supplied guide data and broadcast service-information tables expose different source and field arrangements. A consumer must connect them to its channel identities and clock context. The pages here describe that representation before the server turns it into a displayed schedule.

    • XMLTV
      XMLTV represents channel identities and programme listings in XML, with format-specific timestamps and episode-number systems that a guide importer must interpret.

    • Emby guide data
      Emby guide data supplies supported regional programme listings whose lineup selection, station mapping and loaded horizon determine the guide shown by the server.

    • DVB Service Information
      DVB Service Information describes broadcast services, programme events and timing context through tables that a receiver must collect, interpret and associate with the selected service.

    • ATSC PSIP
      ATSC PSIP connects virtual-channel identity with event descriptions, table-discovery information and a GPS-based system clock in the ATSC 1.0 broadcast environment.
