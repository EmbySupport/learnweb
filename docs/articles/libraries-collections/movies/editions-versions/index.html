    Overview: Editions and versions

    Editions, versions and multipart structures describe different relationships among files associated with a movie.

    A different cut changes the edition; another encoding can provide a version of the same content; a split feature can require several parts. Those arrangements call for different catalogue and playback relationships. The three pages here establish the intended relationship before the files are grouped or selected.

    • Movie editions
      A movie edition identifies a particular cut or presentation of a film whose content and timeline may differ from other releases.

    • Alternate media versions
      Alternate media versions provide different playable representations of a catalogue item, each with its own technical properties and resource identity.

    • Multipart movies
      A multipart movie divides one intended feature across sequential resources whose local timelines must be interpreted as parts of a whole.
