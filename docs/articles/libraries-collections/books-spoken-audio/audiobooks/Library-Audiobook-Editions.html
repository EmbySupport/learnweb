    Audiobook editions and narrated versions

    An audiobook edition identifies a particular narrated presentation whose reader, language, text selection and timeline can differ from other versions of the same book.

    The same book can be read by different narrators, translated, abridged or presented as a dramatized production. An audiobook edition identifies the particular presentation the listener is choosing.

    A new codec is a technical representation change. A new reader or a different text selection can change the performance and its timeline.

    Fictional edition of The Lantern Keeper Reader Text selection Duration in this example
    E1 Nora Hale Unabridged 90 minutes
    E2 Nora Hale Abridged 60 minutes
    E3 Dane Rowan Unabridged 105 minutes

    The durations are invented. A shorter recording does not alone prove abridgement: reading pace, pauses and other presentation choices also affect length.

    Text and performance are related identities

    An unabridged label describes the intended text coverage for the represented edition. It does not establish that two readings have identical pauses, pronunciation, introductions or chapter times.

    An abridged presentation changes what is included. A dramatization can change speakers and adapt the text into another form. Those choices matter even when all versions retain the underlying book title.

    A translation adds another textual relationship before the narration is considered. Two English encodes of E1 can correspond to the same performance; an English and French reading cannot be aligned merely by matching their title labels.

    Schema.org's audiobook description has separate author/reader, edition, language and abridgement concepts. Those fields illustrate the information a description may preserve; they are not a list of dedicated fields guaranteed in every Emby app.

    Publication identifiers select products

    An ISBN identifies a publication's edition and format in the ISBN system. It is not an audio hash or a location within a narrated performance. A catalogue's book/work identity can be broader still.

    Thus an identifier can help distinguish a published audiobook product without supplying any timing correspondence to another narration. Conversely, a recording re-encoded from FLAC to AAC can preserve its performance while changing bytes and technical properties.

    Emby's book documentation describes library resource recognition. A library can recognise two files under familiar book names while still needing enough edition context to explain which narration each file represents.

    Chapter anchors reveal different pacing

    For E1, story chapter 3 begins at minute 53. For E3 it begins at minute 67 in this original example. Those known boundaries identify the same structural place in the text at different performance times.

    A position eight minutes after E1's chapter-3 start is book minute 61. Adding eight minutes to E3's boundary yields minute 75, but that is only an elapsed-time guess. Dane Rowan can spend a different amount of time on each sentence, so equal time since the chapter start does not establish the same spoken passage.

    Preserving the chapter gives a meaningful broad continuation point. Preserving an exact passage requires more detailed correspondence between the text and each performance. Multiplying a whole-book percentage by the destination runtime supplies neither.

    Labels should distinguish what the listener hears

    A useful edition description includes the reader, language and abridgement or adaptation status when those distinguish available choices. Nora Hale, unabridged conveys a different decision from AAC, 128 kbit/s.

    The performance label and technical source label can both be retained. That lets a listener choose E1's narration and then use a suitable resource representation, while E3 remains a different reading rather than an unexplained “higher-duration version.”
