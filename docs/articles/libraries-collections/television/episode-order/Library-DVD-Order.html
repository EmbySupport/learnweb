    DVD episode order

    DVD episode order describes an episodic release arrangement that can change numbering, grouping or segmentation relative to broadcast order.

    DVD order names a catalogue arrangement associated with an episodic disc release. It can differ from broadcast order because episodes were rearranged, grouped into different seasons or presented as combined programmes.

    The label describes the release arrangement, not the encoded file format. An MKV extracted from a DVD can retain DVD numbering. A DVD-Video resource can contain episodes that the catalogue numbers in aired order. Changing the container does not choose the episode order.

    Disc numbers are storage coordinates

    Disc label What it establishes What it does not establish
    Season 1, disc 2 A disc in that particular box set Catalogue season 2
    Programme 3 on disc 2 A selectable programme on that disc Series-wide episode 3
    Bonus disc A supplementary resource grouping A provider's season-zero episode identities

    Disc layouts can include menus, multiple programmes and extras. Their physical positions are not a universal series-numbering system.

    A catalogue's DVD arrangement can instead assign explicit season/episode coordinates. In the fictional Harbour Watch example, The Missing Boat is DVD S01E02 and aired S01E03. Matching its file as aired E02 would retrieve the wrong story even though the disc extraction and filename parsing succeeded.

    One DVD programme can represent two episodes

    Suppose a DVD programme contains two 22-minute stories in a 44-minute resource. A broadcast catalogue may describe those stories separately. A DVD arrangement may describe their combination.

    This is not only a permutation. The relationship between the resource and catalogue episodes has changed. TheTVDB's multi-segment policy explicitly addresses combined DVD entries, illustrating why the chosen catalogue can have different episode entities across orders.

    A filename range can describe coverage of two episodes in a library that supports that relationship. It does not provide the exact point inside the video where the second episode begins. Multi-episode files explains that distinction.

    Match the release before translating numbers

    The useful evidence is the release's actual episode sequence, story titles and segmentation, plus the catalogue arrangement that describes them. A general “DVD” label may be insufficient if another region's box set has a different cut or programme layout.

    A correct series identity narrows the candidates, but a coordinate still needs its arrangement. Translation works by resolving the actual episode and finding its coordinate under the target order; a universal offset between aired and DVD numbering does not exist.

    Emby's TV naming documentation describes supported resource naming. Provider arrangements still need representation in the integration being used. For The Missing Boat, the mapping remains concrete: resolve the DVD programme's story, then associate it with aired S01E03 if that is the target catalogue arrangement.
