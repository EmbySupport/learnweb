    Aired episode order

    Aired episode order assigns episode coordinates according to a catalogue’s broadcast or release arrangement for a television series.

    Aired order describes the sequence a catalogue assigns to a show's broadcast or initial release arrangement. It is commonly the default numbered arrangement, but the word aired does not supply a universal ordering rule independent of that catalogue.

    TheTVDB's API documentation says its default order is generally aired order. That describes a catalogue convention. It does not imply that every broadcaster, region or later release used the same sequence.

    Production and broadcast can disagree

    A fictional show supplies this example:

    Story Production position Broadcast coordinate
    Arrival 1 S01E01
    The Missing Boat 2 S01E03
    Night Signal 3 S01E02

    Production position describes the making or intended production sequence. Broadcast coordinate describes the aired arrangement. A production code printed on a script is therefore not automatically a filename-ready episode number.

    The distinction explains why story continuity can appear unusual under aired order without the library having misread the files. A network can change the release sequence; the catalogue can accurately record that sequence.

    An air date supplies evidence, not the complete key

    Two episodes can be released on the same day. A streaming season can be released as a batch. A programme can have several regional air dates. Sorting dates alone may therefore leave ties or select the wrong release context.

    An aired coordinate typically retains season and episode position, while a date field records a release event. Both can be useful without being interchangeable.

    For daily programmes, a date-based episode may supply a better naming clue than an enormous season counter. The date still needs the series and catalogue context to locate the right entry.

    Recognizing a correct aired match

    If a local file contains Night Signal and the catalogue's aired arrangement assigns it S01E02, then that coordinate is consistent with its story. If the file was named from a DVD arrangement that calls The Missing Boat E02, the same coordinate text can lead to a different match.

    The decisive check is the episode identity and content, not whether the number looks plausible. Understanding episode order works through that translation in detail.
