    Dialogue normalization (dialnorm)

    Dialnorm is dialogue-level metadata in Dolby Digital and related Dolby audio systems. It tells the reproduction system how the programme's dialogue reference relates to digital full scale, allowing programmes to be reproduced at a more consistent dialogue level.

    It is not a speech detector, an instruction to raise only the centre channel, or a compressor that turns down explosions. The resulting gain applies to the programme.

    From the stored number to the gain

    In the AC-3 syntax, the valid unsigned values 1 through 31 indicate how many decibels the dialogue reference lies below full scale. A stored value of 27 corresponds to a dialogue reference of −27 dB. Media tools often display the signed reference rather than the unsigned field.

    Using the reproduction reference of −31 dB, the gain is:

    gain = stored value − 31 dB
    Stored value Dialogue reference Programme gain Amplitude multiplier
    31 −31 dB 0 dB 1.000
    27 −27 dB −4 dB 0.631
    21 −21 dB −10 dB 0.316

    For value 27, dialogue represented at −27 dB becomes −31 dB after the −4 dB adjustment. A musical or effects component in that programme also receives −4 dB. The contrast between that component and the dialogue remains intact.

    Dialnorm's historical reference convention should not automatically be relabeled as a whole-programme integrated LUFS reading. What was measured, how dialogue was identified, and the mastering method determine what the metadata describes.

    Metadata and the actual mix need to agree

    The field declares a level; it does not inspect the signal during playback to discover whether that declaration is correct. If two otherwise identical encodings carry values 31 and 27, a reproduction path applying dialnorm gives them different gains even though the encoded sound content may be the same.

    Conversely, deliberately loud and quiet passages within one programme remain loud and quiet relative to each other. Dynamic range compression supplies time-varying treatment when that contrast needs changing. AC-3 has separate metadata for such dynamic treatment.

    The gain belongs to a reproduction stage

    With bitstream passthrough, the receiver can decode the Dolby stream and use its dialnorm information. When a player delivers decoded PCM, an earlier decoding or reproduction stage can have incorporated that gain. The volume selected by the listener is another factor in the final reproduction level.

    This is useful when comparing Emby routes that sound different at the same displayed volume. Establish where the Dolby stream was decoded and where metadata gain was applied. Applying the same −4 dB adjustment twice would produce −8 dB; ignoring it would leave the programme at its unadjusted reference. A receiver's codec label or an app's volume number alone does not identify either situation.
