    Dolby MAT Audio Transport

    Dolby MAT means Metadata-enhanced Audio Transmission. It packages audio for a supported HDMI output path and is especially useful when interpreting the relationship between a player's decoding and a receiver's Atmos input.

    MAT is a transport mechanism. It is not evidence that the movie file itself stores a “MAT soundtrack.”

    Two important uses

    MAT use What is carried
    Original TrueHD transport, commonly associated with MAT 1.0 Variable-rate TrueHD data packed for a fixed-rate HDMI audio link
    MAT 2.0 Atmos delivery Supported PCM-based object audio with metadata for further rendering

    Dolby's home theater description explains the extension to PCM-based Atmos delivery. Microsoft's transport documentation distinguishes MAT versions and their output declarations. These version-specific capabilities should not be collapsed into one generic PCM claim.

    Decoding can preserve spatial information

    An object-aware playback path can decode compressed Atmos content and then deliver audio plus its associated metadata through MAT. The receiver can use that information for its renderer.

    By contrast, sending only an ordinary 5.1 or 7.1 PCM channel presentation leaves the receiver without the original object metadata. More output channels alone do not restore it.

    MAT carriage also does not make a lossy source lossless. It can transport the decoded audio without adding a new lossy encoding, while the source's earlier compression remains part of that signal.

    For an Emby session, a MAT input indication can therefore describe what the player is sending after delivery and processing. Confirm the source format and actual output capability together: a receiver supporting one MAT use does not establish that every player can decode or deliver every Atmos source form.
