    Audio Downmixing

    A 5.1 film has center dialogue and surround ambience, but the television accepts two output channels. Downmixing constructs a new two-channel presentation from those source signals. It must decide both which contributions go where and how their levels fit the output range.

    Selecting only the original front pair is not that operation.

    Follow one moment through a stereo matrix

    For a conventional illustrative fold-down, ignoring LFE in this example:

    Left output = FL + 0.707 × C + 0.707 × SL
    Right output = FR + 0.707 × C + 0.707 × SR

    Here FL/FR are front left/right, C is center, and SL/SR are the corresponding surrounds. Real downmix conventions, metadata, and target formats can choose other coefficients and phase relationships.

    Take this particular sample frame:

    Source Value
    FL +0.10
    FR +0.10
    C +0.60
    SL +0.20
    SR −0.10

    The resulting left value is 0.10 + 0.4242 + 0.1414 = 0.6656. The right is 0.10 + 0.4242 − 0.0707 = 0.4535.

    The center has contributed to both sides; the different surround values retain different contributions. Taking FL and FR alone would instead output only +0.10 and +0.10, losing those stronger parts of the moment.

    Leave headroom for coincident signals

    With FL=C=SL=+1, that illustrative left sum is 1 + 0.707 + 0.707 = 2.414. The individual inputs are in range, but their sum is not.

    A simple worst-case normalization for this particular matrix could scale the sum by 1/2.414, approximately 0.4143. Other approaches can use different target levels, metadata-driven coefficients, or suitable overload protection. A single maximum-sum bound is safe but may leave extra headroom for ordinary material whose peaks do not coincide.

    This explains why a downmix can be quieter without changing codec quality, and why compensating with a later indiscriminate boost can reintroduce clipping.

    Phase and channel roles affect the result

    Opposing contributions can cancel. If the left front signal and a routed surround contribution oppose each other, their combination changes even though both source channels decoded correctly.

    Ordinary stereo and a matrix-surround Lt/Rt presentation can use different relationships, including phase treatment. The intended downstream presentation determines which matrix is appropriate.

    The input layout also must be correct. A center contribution cannot preserve dialogue if software mistakenly interprets that buffer as LFE or a rear channel. Apply the matrix to named roles, not guessed array positions.

    Handle LFE and main bass separately

    The worked matrix omits LFE deliberately. A real conversion chooses its LFE treatment according to the intended presentation. The main channels already contain bass; omitting an effects channel does not erase every low frequency.

    Bass management happens for playback speakers and is another job. It can redirect main-channel low frequencies to a subwoofer after the mix has been constructed.

    Know what can no longer be separated

    After five source signals become two outputs, arbitrary original channels cannot be uniquely recovered. For instance, additional center contribution can be indistinguishable from matching front contributions in the final pair.

    An upmixer can derive useful output directions from that pair, but it does not invert every original component. Retaining the multichannel master preserves those separate signals for a later different render.

    Locate the combination during playback

    An Emby session can downmix in server conversion, the client decoder/processor, or a later output stage. Record the source layout, where the matrix was applied, and the delivered/output layouts.

    For weak dialogue, compare whether center contributions survived. For overload, inspect the sum and its gain. For missing rear activity, determine whether an earlier stereo downmix replaced the discrete source. Each symptom follows a specific property of the combination.
