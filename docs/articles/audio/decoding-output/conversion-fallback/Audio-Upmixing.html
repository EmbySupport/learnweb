    Audio Upmixing

    Upmixing uses more output channels than the source provides. A receiver can spread stereo music across surround speakers, or derive height activity from a conventional movie soundtrack.

    This is processing applied to an existing presentation. It does not prove that the source contains an immersive mix.

    Listening result What the processing can do
    The same signal from several speakers Duplicate or redistribute channels
    A stronger central image Derive center activity from relationships between channels
    Surround ambience Analyze and redistribute less central or less correlated material
    Height-speaker activity Derive output for an expanded speaker layout

    Methods differ. Matrix decoding can recover cues deliberately encoded into a stereo signal. An adaptive upmixer can also infer useful spatial behavior from ordinary material, but cannot guarantee the original separate studio channels.

    The receiver's mode is not its input

    Dolby Surround and DTS Neural:X are examples of processing used to expand compatible channel-based content. A receiver may show one of these mode names while its input is only 2.0 or 5.1.

    In an Emby movie session, check the receiver's detected input separately from the listening mode. Sound coming from height speakers may be the result of upmixing a conventional track. Native object rendering uses spatial information carried by an appropriate source and supported path.

    Whether an upmix sounds helpful depends on the material and listening arrangement. Comparing the same passage with the processing enabled and disabled can reveal changes to dialogue placement and ambience.

    A downmixed stereo version followed by upmixing is also not equivalent to preserving the original multichannel soundtrack. Once channels were combined, the upmixer has fewer independent signals to work with.
