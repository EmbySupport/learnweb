    Overview: Conversion and fallback

    Audio conversion and fallback adapt a source to the available decoding and listening path.

    An embedded core can supply an alternative decoding route, while downmixing, upmixing and transcoding perform different changes to the signal. The appropriate explanation depends on what changed: coded format, channel arrangement or the representation selected for delivery. These pages make that change explicit for an Emby playback path.

    • Fallback to an embedded audio core
      Core fallback plays an existing compatible audio component when the full presentation is unavailable.

    • Audio downmixing
      Audio downmixing combines a presentation with more channels into an output with fewer channels.

    • Audio upmixing
      Audio upmixing derives a presentation for more output channels from a source with fewer channels.

    • Audio transcoding
      Audio transcoding decodes a source presentation and encodes a new audio stream for delivery or storage.
