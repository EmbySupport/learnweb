    The Audio Playback Path

    The soundtrack in a file and the format arriving at an amplifier are two different observations. Following the stages between them helps explain why a TrueHD source can correctly reach a receiver labeled “PCM,” or why a multichannel source ends up as stereo.

    Original schematic: these are logical stages. A television, soundbar, or integrated player may combine several in one device.

    Delivery comes before output

    Emby's playback method describes what the server sends. Direct Play can deliver the stored track unchanged. Direct Stream can repackage compatible media, and may convert audio while retaining the video. Transcoding creates a new encoded presentation where required.

    After delivery, the player can decode the audio to PCM or send a supported encoded format onward using passthrough. The operating system and physical output then impose their own format and channel requirements.

    Finally, a receiver or DAC turns the delivered presentation into sound. Speaker routing, bass management, headphone rendering, and an optional listening mode can affect this stage.

    Inspect the labels in context

    Start with the selected track's codec and layout. Then check the server session, the player's output choice, and the receiver's detected input, in that order. The receiver's surround-processing mode may be a separate label.

    If a 7.1 source becomes 2.0 PCM, locate where the channel count changed. It could be server conversion, player downmixing, or the output configuration. If the output is 7.1 PCM, the absence of the compressed codec's name on the receiver is not itself a fault.

    This approach is more informative than treating a single “Direct Play,” “PCM,” or “Atmos” label as a description of the entire session.
