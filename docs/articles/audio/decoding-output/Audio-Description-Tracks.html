    Audio-Description Tracks

    Audio description adds narration of important visual information, such as actions, scene changes, expressions, or text that the main soundtrack does not explain. It helps people who are blind or have low vision follow the programme.

    The narration is usually fitted around dialogue and other important sound. It is a different presentation of the programme, not simply a clearer recording of its existing speech.

    Track description Intended role
    English — Main The ordinary English soundtrack
    English — Audio Description English soundtrack with visual description
    English — Commentary A discussion of the programme, often by its creators

    These are illustrative titles. Real files use varied labels, and a language code alone cannot distinguish the roles.

    Complete mix or supplementary audio

    A stored movie can provide a complete alternative mix with the narration already combined with the programme. Selecting that audio track is enough to hear the described presentation.

    Broadcast systems can instead carry supplementary description that a capable receiver combines with the main audio. The supplementary component is not necessarily a complete soundtrack by itself. Its signaling and intended mixing arrangement matter when preserving or converting a recording.

    In an Emby library, keep track titles and language metadata informative so that a described track can be recognized among several audio choices. If the track contains a complete described mix, selecting it should be understood as choosing that presentation, regardless of its stereo or surround layout.

    Audio description must be supplied or created as content. A codec conversion, a louder center channel, or automatic dialogue transcription does not add explanations of visual events. Losing an alternate track during file conversion can therefore remove an accessibility option even when the main soundtrack still plays normally.
