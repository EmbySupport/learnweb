    WMA Lossless Audio

    WMA Lossless preserves the original encoded audio data. It is a distinct Windows Media Audio variant; the ordinary WMA name or extension does not establish that a file is lossless.

    Microsoft identifies the Lossless variant separately from WMA Standard and Professional. This helps explain why support for a typical WMA music file does not guarantee support for an archival WMA Lossless file.

    Detail Useful interpretation
    Lossless codec identification Establishes the compression variant
    Sample rate and bit depth Describe the preserved source audio
    Variable encoded bitrate Reflects source complexity and compression
    WMA extension Describes a file convention, not proof of lossless coding

    A complex passage can require more compressed data than a simple one without changing sample fidelity. Comparing the bitrate to a lossy WMA therefore cannot directly rank audio quality.

    Using a lossless master

    When the source samples fit the destination format, converting WMA Lossless to another lossless codec can preserve the audio. Container bytes and metadata handling may change, so file checksums are not an audio-equality test.

    An Emby client may instead need a lossy delivery conversion. That session no longer preserves the source samples exactly, even though the library file remains lossless.

    Conversely, making a WMA Lossless file from an already lossy recording preserves only its decoded result. The codec can protect the input it receives; it cannot restore information removed before that input was created.
