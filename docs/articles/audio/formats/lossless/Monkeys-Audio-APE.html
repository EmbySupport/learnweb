    Monkey's Audio (APE)

    Monkey's Audio compresses audio without losing the source data. Its familiar file extension is APE. Different compression levels change the balance between compression and processing effort; they do not select different decoded audio quality.

    Choice What changes
    Faster compression setting Usually less encoding effort and a larger result
    Stronger compression setting More processing effort to reduce size
    Verification mode Checks an APE file's integrity
    Conversion to another compatible lossless codec Changes the representation while preserving the audio

    The codec uses prediction and compact coding of the remaining information. The project's SDK and source code are the implementation reference for decoding, encoding, and related file handling.

    An album can still be one audio stream

    APE collections sometimes use a single album file with a CUE sheet describing track boundaries. The CUE sheet does not contain the music and is not part of the compression algorithm. Keeping it associated with the audio can matter when moving such a collection.

    APE tags are another separate detail: they describe metadata and can also occur outside Monkey's Audio files. A tag-format name is not sufficient to identify the soundtrack's codec.

    When an Emby client needs a converted version, a supported lossless conversion can preserve the decoded PCM, while a lossy delivery version introduces its own tradeoff. A smaller APE file than a FLAC made from the same samples does not imply better sound; successful lossless decoding returns the same audio.
