    Apple Lossless (ALAC)

    Apple Lossless, or ALAC, compresses PCM audio reversibly. It is a distinct codec from AAC, even though both commonly appear in files ending in M4A.

    That shared extension is a frequent source of confusion: one M4A can be a lossy AAC music file, while another preserves its encoded PCM samples losslessly.

    Description ALAC meaning
    Codec identifier “alac” Identifies Apple Lossless content
    16, 20, 24, or 32-bit Supported integer PCM sample precision
    One to eight channels Codec capability, subject to supported channel configurations
    M4A or CAF Possible file packaging, not the compression method

    Apple's published reference code and configuration description explain the format and channel mapping. Their included example conversion utility has narrower input support than the codec itself; limits of that tool should not be mistaken for limits of every ALAC implementation.

    Moving between lossless formats

    Converting supported PCM samples from FLAC to ALAC can preserve the audio exactly. The outer file, tags, artwork handling, and compressed bitrate can change. A larger ALAC copy is not automatically better or worse than the FLAC it came from.

    Similarly, converting an AAC file to ALAC preserves the decoded AAC result; it cannot undo the earlier lossy encoding.

    For an Emby music collection, identify the actual codec before diagnosing two M4A files that behave differently. The player's delivery compatibility and its supported sample format remain separate from ALAC's general format capabilities.
