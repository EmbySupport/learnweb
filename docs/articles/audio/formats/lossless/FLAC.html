    FLAC Audio

    FLAC preserves integer PCM audio without compression loss. Its decoder reconstructs the encoded sample values exactly, making it useful for a music master that can later be copied into other listening formats.

    The format is defined in RFC 9639. It supports one to eight channels and sample precision from 4 to 32 bits, although a particular player may support a narrower practical subset.

    FLAC information Useful meaning
    Sample rate and bit depth Describe the preserved PCM audio
    Compression preset Trades encoding effort against file size
    Encoded bitrate Depends on both the source and compression efficiency
    Audio MD5, when present Helps verify the reconstructed sample data

    FLAC's usual compression presets, 0 through 8, do not change decoded quality. A smaller level-8 file and a larger level-0 file made from the same input can restore the same samples.

    Checking the right thing

    FLAC includes frame checks and can carry an MD5 signature for the decoded audio. The reference tool's test mode validates decoding without writing a new audio file. An integrity check establishes consistency with stored checks, not whether the original rip or recording was accurate.

    A native FLAC file can also contain tags and artwork. Repacking or retagging it can change the file checksum while leaving the audio unchanged.

    During Emby playback, FLAC is typically decoded before it reaches an amplifier as PCM. Seeing “PCM” therefore does not indicate that the server replaced the lossless source with a lossy one. Check any server conversion and client resampling separately; lossless storage alone does not guarantee an unchanged output path.
