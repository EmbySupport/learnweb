    WavPack Audio

    WavPack is often found among lossless formats, but a WavPack file is not necessarily lossless. It supports lossless compression, lossy compression, and a hybrid arrangement that can provide both uses from related files.

    The filename ending in WV does not settle which mode was used.

    Three arrangements

    Files used for playback or decoding Result
    A WV made in lossless mode Original supported audio data can be restored
    A WV made in lossy or hybrid mode, alone A lossy reconstruction
    Hybrid WV plus its matching WVC correction file Original audio can be restored when both are used

    In hybrid mode, the WV file is independently playable. The correction file contains the additional information needed for lossless restoration. A decoder must support and actually use that matching correction file; merely placing it somewhere in a library does not establish that it participated in playback.

    More than ordinary integer PCM

    WavPack supports integer PCM, floating-point PCM, and lossless compression of DSD. Its DSD mode uses lossless storage rather than the PCM hybrid arrangement.

    That distinction is useful during conversion. A WavPack containing supported integer PCM can be converted to another suitable lossless PCM codec without changing the samples. A floating-point or DSD source cannot automatically be represented unchanged by a target designed for integer PCM. “Lossless” needs to apply to the particular data, not just appear in both codec names.

    For WavPack music in Emby, inspect the stream's mode and sample representation as well as the delivery method. If a hybrid file plays without its correction information, the fact that a lossless pair exists elsewhere does not make that session lossless.

    Retaining both parts together matters for a hybrid archive. The WV alone can remain useful, but losing the correction file removes the ability to reconstruct the original from that pair.
