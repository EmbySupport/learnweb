    Speech Coding

    A spoken vowel is not a random collection of samples. The vocal source supplies excitation, and the vocal tract shapes its spectrum. Speech coding exploits these relationships to describe a voice with fewer bits than a literal waveform requires.

    Many speech codecs use a signal model that resembles these two jobs: an excitation signal drives a filter whose parameters change with the speech.

    Separate pitch from the spectral shape

    For voiced sound, recurring excitation contributes a pitch pattern. At an illustrative 100 Hz pitch, a period lasts 10 ms. On an 8 kHz sample grid, that is 80 sample intervals.

    The mouth and vocal tract also create resonances. Changing those resonances changes the vowel's character without requiring the same change in pitch. A coding model can therefore describe pitch-related repetition and the shorter-term spectral envelope separately.

    Unvoiced consonants need noise-like excitation rather than a simple periodic pulse. Real speech mixes and changes these behaviors, so a codec sends updated parameters as it progresses.

    Model information Reconstruction role
    Short-term predictor/filter parameters Shape the spectrum
    Pitch-related information Describe useful longer-term repetition
    Excitation information Supply remaining signal detail
    Gains Set the contributions' levels

    Choose a coded excitation by trying reconstructions

    In code-excited linear prediction (CELP), the encoder searches for excitation information that produces a good reconstruction through the synthesis filter. A perceptually weighted error comparison helps choose the candidate and its gains.

    The decoder does not repeat the encoder's whole search. It reads the selected information, reconstructs the excitation, and applies the specified filter/state updates. Compact parameter coding thus describes a time-varying approximation of the recording.

    Algebraic CELP can define excitation patterns through compact rules and pulse positions rather than a large stored waveform dictionary. The result remains driven by the recorded speech's analyzed parameters. It is not text-to-speech and does not require recognizing the words.

    Give the model a sequence of frames

    The codec updates its description over short intervals. A frame must contain enough information for useful analysis, and some encoders need additional look-ahead. Those contribute latency before transport or playback buffering is considered.

    A format can offer several bitrate modes. More coded information can describe excitation or other parameters with greater accuracy, while the decoder follows the selected mode's defined reconstruction.

    Handle pauses without confusing silence and time

    Voice-activity detection identifies periods that can use another coding treatment. In a discontinuous-transmission system, less data can be sent during inactivity while comfort-noise information represents the background.

    The programme timeline still progresses. The receiver uses the format and transport's timing/state rules; absence of a voice packet is not an instruction to join the next word immediately onto the previous one.

    Noise suppression and automatic gain control before encoding are separate processing operations. They change the input the codec receives, whereas the codec describes that input.

    Why a speech model can struggle with music

    An isolated voice often fits prediction and excitation assumptions well. Dense music, applause, or several competing sounds have different structures and may require tools or data the speech-focused model does not provide.

    A narrowband recording also lacks some frequency content before or during encoding. Decoding it onto a 48 kHz output grid cannot recreate those missing frequencies.

    For a voice recording in an Emby collection, intelligibility, encoded bandwidth, model artifacts, and source fidelity answer different questions. Opus illustrates a codec that joins speech-oriented and general-audio tools for programmes whose character changes.
