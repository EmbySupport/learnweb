    AMR-NB Speech Audio

    AMR-NB is narrowband Adaptive Multi-Rate speech coding. It is associated with mobile voice and can appear in older phone recordings and messaging files.

    The codec supports several speech bitrates so that a system can choose an appropriate mode. Adaptive does not mean that the same file can recover more detail simply by being played on a faster network.

    Codec property Value
    Sample rate 8 kHz
    Speech-frame duration 20 ms
    Samples per speech frame 160
    Speech coding modes Eight rates, from 4.75 to 12.2 kbit/s

    Those are coded speech rates; file headers, framing, and silence-related data affect the overall file size.

    AMR-NB is designed for voices in a restricted bandwidth. A thin or telephone-like quality can therefore be an expected property of a valid recording, rather than an Emby playback fault.

    Preserve what is actually there

    An AMR file stores coded frames, while a 3GP file can package them alongside other media. The codec and its storage wrapper should be identified separately.

    Converting AMR-NB to 48 kHz PCM or to a high-bitrate music codec can make a compatible listening copy. It cannot recreate the original high-frequency detail or remove the earlier speech-coding approximation. AMR-WB is a different wideband codec, not an output setting that upgrades a narrowband source.

    For an Emby session, check whether the original speech track is delivered or converted for the client before comparing formats.
