    AMR-WB Speech Audio

    AMR-WB is the wideband member of Adaptive Multi-Rate speech coding. It carries a broader voice spectrum than AMR-NB and is also standardized by ITU-T as G.722.2.

    The similar names G.722 and G.722.2 do not make them the same codec. A decoder must support the specific format.

    AMR-WB property Value
    Sample rate 16 kHz
    Speech-frame duration 20 ms
    Samples per frame 320
    Speech coding modes Nine rates, from 6.60 to 23.85 kbit/s

    The codec uses algebraic code-excited linear prediction. In practical terms, it stores a compact voice model and the information needed to drive it, rather than an exact copy of every source sample.

    Wideband speech can retain more of the upper-frequency cues that make voices sound clear. It is still lossy speech coding, and does not automatically offer faithful music reproduction.

    Recognizing a stored recording

    AMR-WB frames can be stored using the RFC 4867 file format, conventionally ending in AWB, or inside a 3GP container. The header and codec identifier are better evidence than a renamed extension.

    An AMR-WB recording in an Emby library should be evaluated as the source actually encoded. A later high-rate output or conversion cannot make it an uncompressed studio recording, and a client's AMR-NB decoder should not be assumed to decode AMR-WB.

    If a file sounds unexpectedly narrow, inspect its codec and source properties before treating the amplifier's output sample rate as evidence of the recording's bandwidth.
