    Speex Speech Audio

    Speex is an open codec designed for speech. It uses code-excited linear prediction, or CELP, to represent voices efficiently and includes tools useful for packet-based voice communication.

    Speex mode Nominal sample rate
    Narrowband 8 kHz
    Wideband 16 kHz
    Ultra-wideband 32 kHz

    The sample rate helps identify the mode; it is not the encoded bitrate. Each mode can use different quality and bitrate settings. Speex is lossy in all of them.

    Codec versus voice processing

    A Speex-based application may also apply noise suppression, automatic gain control, or echo cancellation. Those processing functions are separate from the coded audio format. A quiet background or a changing recording level does not establish which codec was used.

    Stored Speex can use Ogg packaging, while RFC 5574 defines its RTP payload for communication. The audio format and transport are different pieces of the playback problem.

    The project's current guidance directs new codec uses toward Opus. Existing Speex recordings still require a Speex decoder; they do not become Opus merely because a newer application uses that codec elsewhere.

    In an Emby collection, Speex is more likely to matter as an existing speech source than as a music master. Converting it can help compatibility, but cannot undo its original compression or recover frequencies absent from the selected mode. Check the stored format and any delivery conversion independently.
