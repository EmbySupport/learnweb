    Windows Media Audio (WMA)

    WMA is a family name, not one audio format with one capability set. A legacy music collection, a multichannel video, and a speech recording may use different Windows Media Audio variants.

    That distinction matters when one WMA file plays and another does not. A decoder for the familiar Standard format is not automatically a decoder for every other member.

    Variant Purpose
    WMA Standard General-purpose lossy audio compression
    WMA Professional Lossy audio including multichannel and higher-resolution configurations
    WMA Lossless Preserving original audio data without compression loss
    WMA Voice A separately implemented speech-focused format

    Microsoft's format identifiers distinguish Standard (0x0161), Professional (0x0162), and Lossless (0x0163). Inspection tools can show codec labels derived from these identifiers. The reported variant is more useful than the filename when investigating compatibility.

    Files and the encoded sound

    A file ending in WMA is commonly an audio-only ASF file. ASF can also store audio alongside video. The outer wrapper and the soundtrack's particular codec are separate requirements.

    The same WMA extension therefore does not guarantee the same compression type. Neither a high sample rate nor a large file is reliable evidence that a WMA track is lossless; the codec variant needs to identify that explicitly.

    For an Emby library containing older Windows Media files, inspect the source track before planning a conversion. Re-encoding a lossy WMA as FLAC preserves the decoded approximation, not the samples discarded when that WMA was made.

    If the client needs a different delivery codec, keep the original file available. This preserves the ability to use a different compatible playback path later without repeatedly encoding an already converted copy.
