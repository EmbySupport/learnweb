    DTS Core Audio

    The DTS core is an independently decodable lossy audio component. It provides the conventional DTS Digital Surround presentation and is also present in many DTS-HD movie soundtracks.

    “Core” describes its role in the stream. It is not necessarily a second selectable audio track beside the higher-quality presentation.

    Situation What the core provides
    A conventional DTS soundtrack The main encoded audio
    A compatible DTS-HD stream Audio an older core decoder can use
    Full DTS-HD decoding A foundation that can be combined with extension data
    Core-only fallback A lossy presentation without the full extension result

    DTS Digital Surround commonly delivers up to 5.1 discrete channels at an encoded rate up to about 1.5 Mbit/s. The media report still needs to identify the actual presentation; the name is not a promise that every file has six channels.

    Decoding less is different from re-encoding

    A core-aware player can select an existing compatible component without creating a new lossy encoding. The result still has the losses of that core's original encoding. In particular, a core extracted from DTS-HD Master Audio is not the lossless Master Audio result.

    For an Emby playback session, a receiver showing “DTS” may be receiving this fallback even though the selected source track is labeled DTS-HD. Check the delivered audio and receiver's detected input before assuming that the full extension was decoded.

    The DTS family also permits extension-only arrangements. An embedded core should consequently be confirmed from the actual stream rather than inferred from every filename containing “DTS-HD.” This distinction becomes useful when a player can decode one DTS variant but cannot extract a fallback from another.
