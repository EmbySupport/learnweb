    xHE-AAC Audio

    xHE-AAC is Extended High Efficiency AAC, based on Unified Speech and Audio Coding (USAC) and paired with MPEG-D loudness and dynamic-range control. It is designed to handle speech, music, and mixtures of both across a broad bitrate range.

    That matters for material such as an audiobook with music, a radio programme, or a movie soundtrack. A codec optimized only for speech can struggle when the signal changes character. USAC combines coding tools suited to both speech and general audio.

    Feature Intended benefit
    Unified speech and audio coding Consistent handling of voices and music
    Wide bitrate range Adaptation to different data budgets
    Switching support Smooth transitions among suitably prepared bitrate versions
    MPEG-D loudness and dynamic-range control Controlled playback loudness and optional dynamics adjustment

    These features still require appropriate content preparation and a capable playback implementation. “Adaptive” does not mean that a stored file automatically changes its bitrate without separately encoded delivery versions.

    A new member with a different core

    Despite its AAC-family name, an xHE-AAC stream is not an AAC-LC stream with a few extra tags. An AAC-LC or HE-AAC decoder cannot be assumed to decode its USAC content.

    The xHE-AAC profile provides decoding capability for earlier AAC-family formats, but that relationship does not work in reverse. A broad “AAC supported” statement is consequently too vague for diagnosing a particular xHE-AAC track.

    For an Emby session, distinguish the selected source format from the format delivered to the app. A device's ability to handle ordinary AAC music says little about this newer profile, and a codec's technical capabilities are not a support guarantee for every app using that device.
