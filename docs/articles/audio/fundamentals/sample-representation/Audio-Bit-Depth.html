    Audio Bit Depth

    Bit depth is the precision available for a PCM sample's amplitude. With integer samples, more bits allow more numerical levels across the same full-scale range. They do not add sample positions in time or make the loudest permitted value louder.

    For an integer representation with N bits, there are 2^N possible bit patterns. Each extra bit doubles the number of levels and halves the size of a uniform quantization step.

    Integer bit depth Available levels
    8-bit 256
    16-bit 65,536
    24-bit 16,777,216

    Why the extra precision matters

    Rounding a signal onto those levels produces quantization error. Smaller steps allow quieter signal detail to sit farther above that error. Extra precision is also useful while mixing or adjusting levels, because processing introduces values between the original levels.

    A 24-bit recording can still contain microphone noise, a noisy room, or audio originally captured at lower precision. The file's capacity and the useful detail in its contents are different things. Converting a 16-bit recording to 24-bit storage does not recover information that was never captured.

    Bit depth also needs a qualifier. 32-bit floating-point audio uses a different numerical representation; it is not equivalent to 32-bit integer precision. And a 24-bit sample can occupy a 32-bit storage slot, with only 24 valid bits. PCM sample formats explains those labels.

    If Emby reports a bit depth, use it to describe the audio's representation, not as a quality score. Lossy compressed codecs do not generally have a PCM-style bit depth that explains their compression quality. Their decoded samples still need a working format, which may differ from how the source was recorded.
