    Audio Resampling

    Resampling changes an audio signal's sample rate. It produces values on a new time grid while keeping the intended duration and pitch. It is more than changing the sample-rate number in the file header.

    For example, one second of 44.1 kHz audio contains 44,100 samples per channel. Converting that second to 48 kHz produces 48,000 samples per channel. The new positions generally fall between the old ones, so the converter calculates their values using interpolation and filtering.

    Treatment of a one-second 44.1 kHz signal Samples per channel Resulting duration
    Keep its original rate 44,100 1.000 seconds
    Resample to 48 kHz 48,000 1.000 seconds
    Only relabel it as 48 kHz 44,100 0.91875 seconds

    Calculated example without encoder padding or other timing adjustments. The relabeled case also raises pitch.

    Filtering is part of the conversion

    When reducing the rate, frequencies above the new Nyquist limit must be attenuated to avoid aliasing. When increasing it, the converter must avoid creating unwanted spectral images. The exact filter determines how close the result comes to the desired conversion, including its transition band and processing cost.

    Upsampling does not invent information above the original recording's frequency limit. A 48 kHz file converted to 96 kHz has more sample positions, but that alone does not make the recording more detailed.

    An Emby client, an operating-system mixer, or a server conversion may need a different rate for the destination. If playback is smooth and correctly timed, a rate change is not automatically a problem. The useful questions are whether conversion is required and whether it is performed well. If integer precision is reduced as part of the same processing, dithering is a separate decision.
