    Mono Audio

    Mono audio uses one channel to carry a complete sound presentation.

    Mono is one complete sound signal. It can include an orchestra, dialogue, effects, and ambience, all mixed into that one channel. It is a spatial arrangement, not a measure of how simple the content is.

    Stored arrangement Presentation
    One mono channel One complete signal
    Two identical copies The same mono presentation duplicated
    Two independent mono programmes Different signals that should not necessarily be heard together

    A playback system can send the mono signal to one speaker, both stereo speakers, or another configured output. Two speakers reproducing the same signal do not add a left/right distinction to the source.

    Make mono from stereo

    A simple normalized stereo fold-down is M = (L + R)/2. The factor of one half gives headroom and keeps matching left/right values at their original level.

    Left value Right value Resulting mono value
    +0.4 +0.4 +0.4
    +0.4 0 +0.2
    +0.4 −0.4 0

    The last row explains why phase relationships matter: opposing components cancel when combined. Taking only the left channel avoids that sum but omits anything present only on the right. Choosing a proper mono presentation and taking one side are different operations.

    A mono film soundtrack is also different from the center channel of a surround mix. The mono track contains the whole programme; a surround center is one component among several.

    For an archival mono programme selected in Emby, equal sound from two stereo speakers can be the intended reproduction of the original single signal. Its language, edition, and mix remain more useful selection criteria than the number of physical speakers playing it.
