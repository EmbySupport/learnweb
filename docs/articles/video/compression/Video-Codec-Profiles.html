    Video Codec Profiles

    A codec profile describes a permitted set of tools and sample formats within one codec. It helps establish what a decoder must understand. It is a compatibility description, rather than a picture-quality setting.

    For example, “H.264 support” does not establish support for every H.264 profile. An app's decoder can handle ordinary 8-bit H.264 while lacking a path for a 10-bit variant.

    Profile example Bit-depth support Color sampling in this example
    H.264 Baseline 8-bit 4:2:0
    H.264 Main 8-bit 4:2:0
    H.264 High 8-bit 4:2:0, also monochrome permitted
    H.264 High 10 Up to 10-bit 4:2:0, also monochrome permitted
    HEVC Main 8-bit 4:2:0
    HEVC Main 10 Up to 10-bit 4:2:0

    Selected profile constraints, not the entire feature list or a decoder support guarantee. A permitted maximum does not mean every stream uses it.

    Baseline, Main, and High differ even though their common color depth and sampling can match. For instance, H.264 Main permits coding tools excluded from Baseline, while High adds further tools. The codec specifications define the full restrictions.

    Read the whole description

    A profile belongs to its codec. H.264 High and HEVC Main cannot be ranked by comparing the words “High” and “Main.” HEVC Main 10 also does not mean HDR: a 10-bit stream can carry SDR content.

    Levels and tiers describe another part of compatibility: resource limits such as picture size, throughput, buffering, and bitrate. They should be checked alongside the profile.

    For Emby, a profile mismatch can make video transcoding necessary for a particular app even when another file using the same codec plays directly. Changing the profile label alone does not convert the stream's tools or sample format. The encoded content must actually satisfy the target profile.

    Support depends on the complete playback path, including the app's selected decoder, operating system, and hardware. Treat the media information and the device's documented capabilities as complementary evidence.
