    Video Reference Frames

    A reference frame is a decoded picture kept available for predicting another picture. The decoder stores these pictures in a decoded picture buffer rather than immediately discarding every frame after display.

    Multiple references let an encoder choose useful earlier pictures or combine prediction information. For example, a region briefly hidden behind a moving person may be easier to predict from an older view in which it was visible. Whether extra choices improve compression depends on the content and encoder.

    The buffer contains pictures, not compressed packets

    The memory needed for references grows with resolution and sample precision. For a tightly packed 8-bit 4:2:0 picture with even dimensions, the sample payload is width × height × 1.5 bytes:

    Picture grid Payload for one decoded picture Payload for four
    1920 × 1080 3.11 MB 12.44 MB
    3840 × 2160 12.44 MB 49.77 MB

    Calculated examples using decimal MB. Actual decoder memory can be larger because of alignment, additional working surfaces, display reordering, and different pixel layouts. These are not compressed file sizes.

    A higher bit depth can increase storage further, especially when samples occupy wider memory containers. The number of pictures needed for reordering can also differ from the number actively used as prediction references.

    For Emby playback, a decoder must meet the stream's buffer and prediction requirements as well as recognize the codec. Codec levels place limits on relevant resources, and device support can have additional constraints.

    Reference count is not a quality score. A media inspector may report a maximum or an encoder setting rather than the references used for every picture. A stream with fewer references can still look better if other encoding decisions suit the content.

    Nor are all B-pictures excluded from the buffer. Modern codecs allow structures where B-pictures become references for other pictures. To interpret a dependency chain, examine the actual picture structure rather than treating each letter as a fixed lifetime rule.
