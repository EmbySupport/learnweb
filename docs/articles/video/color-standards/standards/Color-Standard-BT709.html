    ITU-R BT.709

    A media inspector can show “BT.709” in several fields. Each occurrence answers a different question about the same signal:

    Field Meaning of BT.709 there
    Color primaries The red, green, blue, and D65 reference-white coordinates
    Transfer characteristics The source's nonlinear light-to-signal relationship
    Matrix coefficients The conversion between nonlinear RGB and luma/color-difference signals

    BT.709, or Rec. 709, specifies HDTV image and signal parameters. It is the familiar color system for conventional SDR HD video, but those parameters continue to matter when the same signal is carried at another resolution.

    Why one field cannot stand in for the others

    The primaries define what RGB mixtures mean. The transfer characteristic defines how the signal represents light. The matrix describes how nonlinear RGB becomes Y′CbCr. A processing stage can change one of these representations while retaining another, so a reader needs the complete description.

    The nonlinear luma weights are 0.2126R′ + 0.7152G′ + 0.0722B′. Green contributes most strongly to luma under this relationship. These weights differ from BT.601, which explains why using the wrong matrix can shift colored objects. Neutral RGB values produce neutral color differences in both systems, so a gray-only test can miss the error.

    The source OETF and the display response have different roles. BT.1886 supplies a reference SDR display EOTF, including the effect of display black and white. A BT.709 transfer tag identifies the source characteristic; it does not instruct a reader to treat the picture as linear light.

    Put an SDR signal on a wide-gamut screen

    Suppose a television's native primaries reach farther toward saturated red and green than BT.709. The intended BT.709 colors still need to be reproduced as BT.709 colors. The output path can mix the display's primaries to obtain those colors inside its larger gamut.

    Driving the screen's most saturated red for a BT.709 red value would stretch the source gamut, changing the produced image. Correct color management lets the larger panel serve both smaller and wider gamuts. This is relevant to Emby playback even when the server delivers the original file unchanged: the app and display must agree on signal interpretation.

    A 4K file can carry SDR BT.709 video, and an HD file can carry HDR. Resolution identifies the grid; the color fields identify its interpretation. For an HDR-to-SDR conversion, the brightness and color processing must actually produce suitable SDR values, then describe those values using coherent output signaling.

    When recording a playback comparison, keep the source's primaries, transfer, matrix, and range alongside the delivered stream's fields. That makes an apparent “BT.709 mismatch” a specific question about the part of the representation that changed.
