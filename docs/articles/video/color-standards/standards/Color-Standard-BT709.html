    ITU-R BT.709

    BT.709, or Rec. 709, is the standard most closely associated with conventional SDR high-definition video. It specifies more than a color gamut: its parameters also cover the image format and the way picture signals are formed.

    When a media inspector shows “BT.709,” check which field contains it. The same short name can describe different parts of the signal.

    Field What BT.709 identifies there
    Color primaries Red, green, blue, and the D65 reference white
    Transfer characteristics The nonlinear relationship used at the source
    Matrix coefficients The RGB-to-luma/color-difference relationship

    For its nonlinear luma signal, the familiar weights are 0.2126 for red, 0.7152 for green, and 0.0722 for blue. These differ from BT.601. The difference matters when reconstructing color from Y′CbCr.

    “Rec. 709” does not mean “no processing”

    A display with a wider native gamut must still reproduce the intended BT.709 colors. Simply stretching all colors to the display's most saturated primaries can make faces or foliage look unnaturally vivid. A wider-gamut panel is useful when its color management also handles smaller gamuts correctly.

    The source transfer characteristic is also distinct from the display response. BT.1886 specifies a reference SDR display EOTF; it does not rename the file's transfer-characteristic tag to “BT.1886.”

    For an Emby library, resolution is only a clue. A 4K file can contain SDR BT.709 video, and an HD file can contain HDR. Read the signal descriptions together rather than deciding from “1080p” or “2160p.” When HDR is converted for SDR playback, producing a coherent BT.709 output requires both suitable picture values and matching signal labels.
