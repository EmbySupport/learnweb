    ITU-R BT.2100

    BT.2100, or Rec. 2100, specifies the image parameters for HDR television. It brings wide color and HDR transfer functions into a defined system for producing and exchanging television pictures.

    Its two transfer-function systems are PQ and HLG. A playback chain must know which one it is receiving: the same numeric signal value has a different meaning in each system.

    Part of the system BT.2100 specifies
    Color primaries The same wide-gamut primaries as BT.2020
    HDR systems Perceptual Quantizer (PQ) and Hybrid Log-Gamma (HLG)
    Image sizes 1920 × 1080, 3840 × 2160, and 7680 × 4320
    Scanning Progressive
    Signal precision 10 or 12 bits per component

    The current recommendation is BT.2100-3, approved in February 2025. It also defines reference viewing conditions and explains the relationship between the capture, display, and overall transfer functions.

    What it tells you about a file

    A file does not need to show a single “BT.2100” badge. Its metadata may instead describe BT.2020 primaries together with PQ or HLG transfer characteristics and a suitable matrix. Those separate fields describe the signal more precisely than a filename containing “HDR.”

    Consider a 1080p HDR recording. It has fewer pixels than a 4K recording, but can still require HDR-aware playback. Shrinking it to 720p would reduce spatial detail without automatically changing the light-level interpretation.

    For the same reason, an Emby playback conversion must account for output capability as well as resolution. Sending an HDR signal to an SDR output with a different label is insufficient; HDR-to-SDR conversion needs to adapt the picture.

    BT.2100 is a television-system specification, not a video codec. A device's ability to decode a compressed stream and its ability to render that stream's HDR signal are separate requirements.
