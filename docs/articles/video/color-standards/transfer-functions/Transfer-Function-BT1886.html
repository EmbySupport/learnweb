    ITU-R BT.1886

    BT.1886 specifies a reference display EOTF for HDTV production. It provides a consistent SDR target for displays that do not naturally behave like the CRT monitors used in earlier television workflows.

    Its exponent is 2.4, but the complete curve also depends on the display's black and white luminance. With a zero black level, it reduces to a pure 2.4 power curve. With a nonzero black level, the lower part of the response changes.

    Calculated reference curves. Both examples reach 100-nit white; the second has a 0.1-nit black floor. These are illustrative display parameters.

    The equation is L = a × max(V + b, 0)^2.4. The parameters a and b are calculated from measured black and white so that signal values 0 and 1 reach those endpoints. The graph's shadow panel makes the difference easier to see than the full-range panel.

    What it does not change

    BT.1886 describes the display response. It does not change BT.709's encoded signal parameters, and a BT.709 file does not need to be relabeled “BT.1886” for ordinary SDR playback.

    Consider a dark jacket with several almost-black folds. The amount of separation that reaches your eyes depends on the display response and its black floor, as well as the source picture. A gamma label by itself cannot tell you whether those folds remain visible.

    If the same SDR file looks different between an Emby app and another player, compare the output and display modes as well as the server's playback method. A difference near black can arise after decoding. Applying HDR tone mapping to an SDR signal would address a different problem and is not a substitute for correct SDR rendering.
