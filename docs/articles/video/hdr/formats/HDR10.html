    HDR10

    HDR10 is a widely used HDR delivery format. The 10 refers to ten-bit signal precision; it does not mean a 10,000-nit television or ten times the brightness of SDR.

    Its core ingredients have separate roles:

    Ingredient Role
    Ten-bit values Provide finer gradations than eight-bit values
    PQ transfer characteristics Relate encoded values to intended light output
    BT.2020 color signaling Define the color representation
    Static mastering metadata Describe the mastering display used for the release

    Content may also carry MaxCLL and MaxFALL. Those are reported content light levels, not television requirements.

    HDR10 does not specify one universal appearance on every display. A screen that cannot reproduce the source's brightest values still needs to fit the picture to its own range. Static metadata supplies context, while the display or player decides how to use it.

    What the label does not tell you

    HDR10 is not a video codec or a filename extension. A file's codec, container, audio, and subtitles remain relevant to Emby playback compatibility.

    It is also not proof that the content uses the whole BT.2020 gamut or reaches PQ's upper limit. A restrained grade can be fully valid HDR10.

    If an Emby session produces SDR output, the picture needs HDR-to-SDR conversion. Simply removing the HDR10 metadata leaves the original signal values in place. Conversely, adding HDR10 metadata to an SDR encode does not create new highlight information.

    HDR10+ builds on this delivery approach by adding information that can vary with the picture.
