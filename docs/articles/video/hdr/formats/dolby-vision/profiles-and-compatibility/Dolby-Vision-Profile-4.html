    Dolby Vision Profile 4 (Legacy)

    Dolby Vision Profile 4 is a legacy dual-layer HEVC arrangement with an SDR-compatible base. Dolby now lists it among profiles not supported for new applications.

    Property Legacy Profile 4
    Codec precision Ten-bit HEVC
    Picture layers Base and enhancement
    Enhancement resolution One-quarter of the base picture's pixel count
    Base fallback SDR-compatible

    Its ten-bit base is a useful counterexample to the assumption that ten-bit video must be HDR. Precision and the meaning of the signal are different properties.

    Profile 4 should not be confused with Profile 7. Both use two layers, but their compatible base pictures differ. A report that mentions only “dual-layer Dolby Vision” omits that important distinction.

    In an Emby investigation, seeing an SDR output from a compatible Profile 4 base can be a fallback outcome rather than evidence that the entire file was converted. Establish the actual playback method and delivered stream before drawing that conclusion.

    Legacy status also does not mean that every existing decoder has stopped supporting it. It describes Dolby's direction for new applications, not a universal capability statement about installed devices.
