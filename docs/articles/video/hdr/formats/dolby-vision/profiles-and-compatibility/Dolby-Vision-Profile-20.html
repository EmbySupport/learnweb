    Dolby Vision Profile 20

    Dolby Vision Profile 20 extends the delivery system to stereoscopic video: separate views for the left and right eyes. Its 3D form uses Multiview HEVC (MV-HEVC) Main10, rather than placing two reduced-size views beside each other in one ordinary frame.

    Structure What the layers represent
    Profile 20 stereoscopic MV-HEVC Different views of the scene
    Profile 7 base and enhancement layers Components used to reconstruct a Dolby Vision picture

    Those are different uses of the word “layer.” A second eye view is not a Profile 7-style enhancement residual.

    The specification also defines a 2D form using HEVC. Profile 20 therefore does not always mean that a file contains stereo views. The stream and playback capabilities still need inspection; the cited public specification does not make 2D playback a requirement of every approved Profile 20 device.

    Profile 20 has additional metadata-processing requirements. Existing Dolby Vision support for other profiles is not enough to claim support for it. This is particularly relevant when considering an Emby session on a headset or another multiview display: container handling, view assignment, decoding, and Dolby Vision processing must work together.

    Current profile definitions list both a Dolby Vision-specific base form and an HLG-compatible form. That signal-level compatibility should not be read as a promise that an ordinary HLG television can play every packaged stereo stream or reproduce both eye views.

    For a playback report, include whether the content is 2D or stereoscopic, the codec, the base compatibility, and the exact app/device. “Dolby Vision works on this device” leaves the decisive questions unanswered.
