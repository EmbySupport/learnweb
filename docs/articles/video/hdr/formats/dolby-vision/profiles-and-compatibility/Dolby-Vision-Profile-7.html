    Dolby Vision Profile 7

    Dolby Vision Profile 7 is a dual-layer HEVC format used for UHD Blu-ray with an HDR10-compatible base.

    The Dolby Vision UHD Blu-ray workflow prepares three related parts of a Profile 7 presentation:

    Part Role
    Ten-bit HEVC base A complete HDR10-compatible picture
    Enhancement Additional reconstruction information according to the authoring mode
    RPU metadata Dolby Vision information associated with the pictures

    Base and enhancement must stay aligned. The profile defines a dual-layer delivery arrangement rather than two independently watchable releases.

    Choose the reconstruction path, not merely the final indicator

    A supporting Dolby Vision path can use the base, metadata, and relevant enhancement operations. With FEL, the nonzero picture residual supplies information for complete reconstruction. With MEL, no nonzero picture residual needs to contribute, while Dolby Vision interpretation and metadata remain part of the presentation.

    Another path can use the compatible HDR10 base. That gives a valid HDR10 image if the surrounding container, codec, and output path support it. It can be an intentional fallback rather than damaged content.

    The two paths use different information. A Dolby Vision output indicator identifies a presentation mode, while confirming an enhancement contribution requires evidence of the decoder/composer operations. An HDR10 indicator can instead describe the compatible-base path.

    Profile 7 data after a remux or conversion

    Moving preserved coded data from disc packaging into another container changes the reader's arrangement, not the source's required reconstruction jobs. The destination app needs to locate and process the layers correctly. A disc player and an app receiving a file can consequently choose different available paths.

    A conversion to a single-picture-layer profile also needs its operation described. Did it keep the base, transform the metadata, or omit enhancement information? Copying the base without re-encoding preserves that coded base, while a discarded FEL can remove information from the original complete presentation.

    For an Emby comparison, record the source layer type, delivered stream, player support, and output mode. Those observations distinguish preserved Profile 7 delivery, compatible-base playback, and a newly prepared rendition.
