    Dolby Vision Profile 7

    Dolby Vision Profile 7 is the dual-layer format used in the Dolby Vision UHD Blu-ray workflow. It combines an HDR10-compatible base with an enhancement layer and Dolby Vision metadata.

    Part Purpose
    Base layer A complete HDR10-compatible picture
    Enhancement layer Additional reconstruction information, according to the authoring mode
    RPU metadata Dolby Vision processing information associated with the pictures

    A non-Dolby Vision HDR10 path can use the base picture, provided the container, codec, and playback path are otherwise supported. That fallback is an intentional property of the format, not a sign that the file has necessarily been damaged.

    For full Dolby Vision reconstruction, the enhancement details matter. A minimum enhancement layer has no additional picture residual to reconstruct. A full enhancement layer carries a nonzero residual. These can place different demands on a decoder even though both files say Profile 7.

    When the same movie behaves differently in an Emby app and a disc player, compare the complete delivery path. Moving compressed data into another container does not automatically give the destination player the disc player's Dolby Vision decoding capabilities.

    A Dolby Vision indicator is useful evidence about the selected output mode, but it is not proof that every original enhancement-layer contribution survived or was used. Conversely, an HDR10 indicator can describe a valid fallback picture.

    If a tool converts Profile 7 to a single-layer profile, examine what happened to the enhancement layer and metadata. The new label alone does not establish that all the original reconstruction information was retained.
