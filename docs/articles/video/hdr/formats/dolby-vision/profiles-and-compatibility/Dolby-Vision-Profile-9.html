    Dolby Vision Profile 9

    Dolby Vision Profile 9 is an unusual reminder that Dolby Vision does not always mean ten-bit HEVC. This profile uses eight-bit AVC, also called H.264, with an SDR-compatible base.

    Property Profile 9
    Compression AVC/H.264
    Coded precision Eight bits
    Dolby Vision picture enhancement layer None
    Base compatibility SDR

    The base and Dolby Vision presentation are different interpretations of the delivered system. A compatible ordinary AVC/SDR path can use the SDR base without providing the Dolby Vision result.

    The eight-bit label describes the coded base signal; it is not a complete description of the Dolby Vision processing or final display signal. Equally, Dolby Vision metadata is not a guarantee that the source contains the same precision or grade as another release.

    For Emby troubleshooting, a player successfully decoding H.264 establishes only codec compatibility. Using Profile 9 as Dolby Vision also needs support for that profile and its metadata path. A result that appears as SDR may be using the intended fallback.

    Avoid interpreting “9” as a quality tier above Profile 8. Profile numbers distinguish delivery arrangements; the film's mastering and compression remain separate questions.
