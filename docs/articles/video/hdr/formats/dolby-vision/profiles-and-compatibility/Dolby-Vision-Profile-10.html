    Dolby Vision Profile 10

    Dolby Vision Profile 10 brings Dolby Vision delivery to AV1. It uses a single ten-bit picture layer with metadata carried in AV1's metadata structure.

    Variant Base-picture compatibility
    10.0 Dolby Vision-specific interpretation
    10.1 HDR10-compatible
    10.4 HLG-compatible

    These are different base arrangements within the profile, not three steps on a quality ladder. Dolby's Profile 10 introduction describes using an existing Dolby Vision master to prepare AV1 delivery; a new profile number does not inherently mean that the film was remastered.

    For an Emby playback path, there are two separate capability questions: can it decode AV1, and can it use this Dolby Vision profile? Support for HEVC-based Dolby Vision does not answer either question by itself. Likewise, AV1 hardware decoding alone does not establish Dolby Vision Profile 10 support.

    The fallback picture also depends on the variant. A properly supported HDR10 or HLG base can be useful when Dolby Vision processing is unavailable, while the 10.0 signal needs the appropriate interpretation or conversion.

    Changing a container or codec label cannot turn HEVC Profile 8 into AV1 Profile 10. The compressed picture format differs, so a real change of codec requires decoding and encoding. Metadata handling must stay consistent with the resulting pictures.

    When comparing files, retain the codec and base-compatibility details alongside the Dolby Vision label. They explain far more about a playback mismatch than the profile number alone.
