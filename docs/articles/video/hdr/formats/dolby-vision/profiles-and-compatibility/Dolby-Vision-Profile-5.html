    Dolby Vision Profile 5

    Dolby Vision Profile 5 is a single-layer ten-bit HEVC format whose base signal is not ordinary HDR10 or SDR.

    A Profile 5 file can decode as HEVC yet show badly shifted colors if its samples are sent through an ordinary HDR10 interpretation. The compression decoder and the signal renderer have different jobs.

    HEVC decoding and Profile 5 color interpretation

    Profile 5 carries a single ten-bit HEVC picture layer with Dolby Vision RPU metadata. Its signal uses PQ with reshaping and the IPT-PQ-C2 component representation. It does not provide an ordinary HDR10 or SDR-compatible base.

    The HEVC decoder reconstructs those coded component samples. The Dolby Vision processing path then supplies their required interpretation and associated operations. Treating the decoded components as conventional BT.2020 YCbCr would use a different relationship to reconstruct color.

    That difference explains why a codec-capable player can produce an image while rendering it incorrectly. The necessary next stage is appropriate interpretation or a real conversion to another coherent representation.

    Required job Evidence to look for
    Open the delivery Supported container and configuration
    Decode the picture Ten-bit HEVC capability
    Interpret Profile 5 Supported reshaping, color, and metadata operations
    Present the result A suitable output/rendering path

    Removing metadata or changing labels leaves the underlying picture representation in place. It does not reconstruct a new HDR10 or SDR picture from those values.

    During Emby playback, inspect the selected app and delivered rendition as well as the stored source. A server conversion can prepare another output if the path supports the required source interpretation. Direct delivery needs that interpretation later in the route.

    Profile 8.1 makes a different choice by providing an HDR10-compatible base. The contrast identifies why one source can have a straightforward base fallback while another needs Profile 5-aware processing.
