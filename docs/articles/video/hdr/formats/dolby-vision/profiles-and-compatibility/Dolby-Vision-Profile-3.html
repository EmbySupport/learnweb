    Dolby Vision Profile 3 (Legacy)

    Dolby Vision Profile 3 is a legacy dual-layer eight-bit HEVC format without a standard HDR10 or SDR-compatible base.

    Dolby Vision Profile 3 is a legacy dual-layer HEVC arrangement. Dolby lists it among profiles not supported for new applications; the record is useful when identifying older material.

    Legacy property Profile 3
    Coded precision Eight-bit HEVC
    Picture structure Base plus enhancement
    Layer resolution relationship Equal resolution
    Base compatibility No standard HDR10 or SDR fallback

    An archived file using this arrangement needs its own supported interpretation or a real conversion. Current support for another Dolby Vision profile does not establish Profile 3 capability. Because the base has no standard HDR10/SDR interpretation, discarding the additional Dolby Vision information does not create either output. Keep the original and its complete profile record when preparing a supported viewing rendition.
