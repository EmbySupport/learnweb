    Dolby Vision RPU Metadata

    Cut the first second from a 24-frame-per-second movie while leaving its metadata associations unchanged. The new first picture is the old picture 24, but it could receive information for old picture 0. Dolby Vision RPU data needs to remain associated with the pictures it describes.

    New frame Correct source association Wrong association if old metadata starts unchanged
    0 Old picture 24 and its metadata Old metadata 0
    1 Old picture 25 and its metadata Old metadata 1
    2 Old picture 26 and its metadata Old metadata 2

    An illustrative frame-alignment problem. Actual metadata can describe a shot or frame, and the packaging determines its association.

    What the RPU carries

    RPU is the conventional name used for Dolby Vision metadata in bitstream and media reports. Its information supports the relevant picture interpretation, reconstruction, and display management. It is different from a coded movie image or an audio track.

    Depending on the profile and metadata version, the workflow can include picture analysis, target-display trims, and active-picture-area information. Analysis describes characteristics of the produced image; trims adjust its mapped appearance; active-area information distinguishes the image from surrounding letterbox regions.

    For HEVC-based delivery, the data is carried in special units associated with the encoded pictures. Other codecs define another carriage. A report of BL+RPU names a base picture plus metadata; BL+EL+RPU also includes an enhancement layer.

    Why an edit can affect the result

    Metadata prepared for a bright exterior should not be used as if it described an adjacent dim shot. An association error can change mapping inputs or creative adjustments at the wrong moment, potentially causing unwanted shifts. A simple offset, reordered frames, a dissolve, or another version of the film can all change that relationship.

    Picture modifications can matter even with unchanged timing. Cropping can change active-area coordinates. A new grade can change the characteristics that analysis described. A correct operation preserves or deliberately recreates the appropriate relationship rather than merely copying a block with the same title.

    Inspect presence, association, and use separately

    For an Emby source, an RPU-present report establishes that metadata was detected. Next inspect whether server delivery retained it or produced a new rendition. Then determine which profile operations the app and output path use.

    A supported compatible base can sometimes provide another valid presentation if Dolby Vision metadata is unused. A Dolby Vision-specific signal needs the relevant interpretation or conversion. The fallback article explains that difference.

    To investigate a brightness change across a cut, compare the exact video version, frame timing, metadata associations, and delivery path. That locates the operation that may have detached the instructions from the image.
