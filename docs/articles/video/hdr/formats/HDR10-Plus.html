    HDR10+

    HDR10+ adds dynamic metadata to an HDR10-compatible picture. This gives a supporting playback system more information about the current scene when fitting it to the display.

    Consider a film that cuts from a dim candlelit room to a bright snowfield. A single program-wide maximum cannot describe the distribution of brightness in both scenes very well. HDR10+ metadata can provide information specific to each scene or frame.

    Playback path How the information can be used
    HDR10+ processing available Dynamic metadata can guide the adaptation
    HDR10 processing available, HDR10+ ignored The compatible HDR10 picture can still be used
    SDR output required The picture still needs HDR-to-SDR conversion

    The dynamic metadata is standardized in SMPTE ST 2094-40. It describes characteristics and mapping guidance; it is not a second image layer containing extra picture detail.

    Dynamic metadata cannot recover detail already removed during mastering or compression. It also cannot make two displays with very different brightness and color capabilities look physically identical. Its benefit is better-informed adaptation of the available picture.

    In Emby, separate the source format from the whole playback path. The file may contain HDR10+ metadata, but retaining and using it depends on the delivered stream, player, output connection, and display. A television showing ordinary HDR rather than HDR10+ can be using the compatible base picture; that is a different outcome from a failed decode.

    When comparing the two modes, use the same release and scene. A different encode or grade can create a larger difference than the metadata system itself.
