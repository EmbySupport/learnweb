    Two-Pass Video Encoding

    Two-pass encoding usually means analyzing the complete source in a first pass, then using those statistics to allocate data during the final encode. It is especially useful when an offline conversion must meet a target average bitrate or approximate size.

    The first pass can identify where the difficult scenes occur. The second pass can reserve more of the available budget for those sections instead of making every decision with only limited knowledge of what comes next.

    Conceptual whole-source workflow. The second pass reads the original source again; it does not encode the first pass's compressed pictures.

    Analysis is not an extra generation of picture loss

    The final encoder uses statistics from the first pass, rather than treating a lossy first-pass video as its new source. Two passes therefore do not automatically mean two successive lossy generations.

    Whole-source two-pass encoding What follows
    First pass observes the source Statistics describe its coding difficulty
    Second pass uses that information The overall budget can be allocated with hindsight
    Source is available twice Suits offline work more naturally than immediate playback
    A fixed target is still required The method cannot eliminate a too-small data budget

    This differs from hardware multipass frame encoding. For example, NVENC can analyze and encode a frame in multiple internal passes. That is not the same as scanning an entire film before encoding it again. An encoder's “two-pass” label needs its documented context.

    For Emby, whole-source two-pass processing is a useful concept when preparing a library derivative in advance. A playback transcode must normally begin delivering before the whole source could be analyzed, so its decisions operate under different timing constraints.

    If exact size is unnecessary, quality-based encoding can be a more direct way to choose acceptable pictures and let size vary. Neither method restores detail already missing from the source.
