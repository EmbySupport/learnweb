    VMAF Video Quality Metric

    VMAF, or Video Multi-Method Assessment Fusion, is a video-quality metric developed by Netflix. It compares decoded test pictures with a reference and combines measured features using a model trained against viewer judgments.

    Its score is a prediction within that model's context. A result of 95 does not mean “95% of the original information,” and a high score does not prove mathematical losslessness.

    Part of a VMAF result Why it belongs with the number
    Model and version Determine the features, calibration, and score convention
    Viewing assumptions Display size and distance affect artifact visibility
    Input preparation Scaling, sample format, and alignment affect the comparison
    Temporal aggregation A film average can hide poor individual scenes

    There is more than one score scale

    Many familiar VMAF models use a 0–100 operating range. That is not a universal definition of VMAF: among the v1 models released in June 2026, Netflix documents a 4K model for viewing at three screen heights with a 0–110 range. Other v1 viewing models use 0–100. Clipping settings can also affect how a score is reported.

    Use the selected model's documentation before comparing scores, especially across resolutions or model generations. A number from one viewing context cannot establish equal perceived quality in another.

    VMAF also needs corresponding pictures. A timing offset, different crop, or unintended color conversion can measure a preparation error rather than compression quality. The comparison should reflect the intended display processing consistently.

    For Emby library conversions, VMAF can help compare candidate encodes made from the same retained source. Inspect difficult scenes and per-scene results alongside the aggregate score. Grain, enhancement filters, and unusual content can expose limitations in a metric's prediction.

    This is an evaluation of decoded pictures. It does not establish app compatibility, real-time transcoding speed, smooth network delivery, or the quality of a source that was already damaged.
