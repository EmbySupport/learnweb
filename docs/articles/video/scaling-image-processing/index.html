    Overview: Scaling and image processing

    Video scaling and image processing reconstruct samples and alter picture detail for the intended presentation.

    Changing picture dimensions requires a rule for estimating samples. Chroma upsampling applies a related reconstruction question to color components, while cleanup operations address noise, bands or edge appearance. This branch connects the chosen filter to the detail and artifacts visible in the result.

    • How video scaling works
      Video scaling constructs a new picture grid by mapping output positions into the source and filtering the samples that contribute to each result.

    • Chroma upsampling
      Chroma upsampling reconstructs color-difference values at the positions required by a fuller picture or output grid.

    • Scaling kernels
      Scaling kernels define how neighboring source samples contribute to a reconstructed output sample.

    • Scaling ringing
      Scaling ringing is overshoot and oscillation around picture transitions caused by the reconstruction filter's response.

    • Spatial aliasing
      Spatial aliasing occurs when a sample grid represents fine picture variation as a different, often coarser pattern.

    • Image cleanup
      Image-cleanup filters alter bands, noise or edge contrast through distinct processing goals.
