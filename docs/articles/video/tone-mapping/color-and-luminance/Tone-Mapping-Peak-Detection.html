    Peak-Luminance Detection for Tone Mapping

    A tone mapper needs some idea of how much brightness it must fit into the output. That information can come from metadata, a configured assumption, or analysis of the decoded picture. Peak detection examines the picture itself. It does not measure the physical brightness of your television.

    The distinction matters because several different numbers can accompany HDR video:

    Value What it describes
    Mastering-display maximum The upper luminance capability reported for the display used in mastering
    MaxCLL The reported maximum content light level
    MaxFALL The reported maximum average light level of a frame
    Detected peak An estimate derived from the pixels currently being analyzed

    FFmpeg's metadata definitions keep mastering-display information and content light levels separate. None of these values is the target screen's measured peak.

    One unusually bright pixel can matter

    Using the brightest pixel is straightforward, but a tiny sparkle may then influence how the whole frame is mapped. Some implementations can instead choose a very high percentile of the brightness distribution. This discounts a small number of extreme values, trading possible loss in tiny highlights for more room elsewhere.

    libplacebo exposes this distinction. It also smooths measurements over time; without smoothing, small changes between frames could cause distracting brightness fluctuations. The balance between stability and reacting to a new scene is covered in scene-adaptive tone mapping.

    This explains why selecting the same curve name does not always reproduce the same picture. Two implementations can feed that curve different peak estimates. When comparing an Emby result, include a dim scene with isolated lights as well as a bright outdoor scene. A single paused frame does not reveal whether the estimate remains stable during motion.

    Peak detection can improve decisions when metadata is absent or unhelpful, but it adds processing work and remains an estimate. It cannot recover detail already clipped in the source.
