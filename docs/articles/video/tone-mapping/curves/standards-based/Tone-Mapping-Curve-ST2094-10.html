    Tone Mapping Curve: ST 2094-10 in libplacebo

    SMPTE ST 2094-10 describes dynamic metadata for a color-volume transform. libplacebo's option with this name implements a brightness-mapping function based on the standard's informative Annex B.2.

    A useful way to picture it is as a curve constrained by three points: the dark end, the bright end, and an adaptation point between them. Moving the middle point changes the treatment of ordinary scene brightness.

    libplacebo 7.360.1, default constants, 1,000 → 100 nits, zero black levels, no scene-average value. The default adaptation-point selection is used.

    A family of curves

    The line shown is not a fixed curve embedded in every ST 2094-10 picture. Source statistics and target assumptions can select a different middle point. The resulting curve may therefore change with the content.

    That also explains why a maximum-brightness value alone does not fully describe an adaptive mapping. Two scenes with the same brightest reflection can have very different average brightness.

    There are boundaries to the option's name. The standard contains more than this brightness function, and libplacebo documents that its mapper does not implement the subjective gain, offset, and gamma controls described in Annex B.3.

    Selecting this curve is consequently not equivalent to decoding and reproducing the complete Dolby Vision processing chain. A curve label cannot establish profile support, enhancement-layer use, or preservation of all metadata.

    For Emby troubleshooting, separate those format/decoding questions from the mapping applied after decoding. The playback path tells you where that work happens; the mapper's implementation and input information tell you which member of this curve family is used.
