    Tone Mapping Curve: Clip

    Clipping is a hard limit. Values that fit are retained; values above the output ceiling all become the same maximum value.

    FFmpeg 8.1 clip, scale parameter 1. Input and output are relative linear light for neutral gray; output white is 1.

    The flat line explains the visible failure. A bright cloud might contain values of 2, 4, and 8. All three become 1, so their brightness differences disappear. The pixels are still present, but the texture represented by those differences is gone.

    Input Output
    0.2 0.2
    1 1
    2 or 8 1

    When the limit is useful

    A hard limit is easy to understand and provides a reference when examining another curve. Below the ceiling, there is no brightness redistribution from this operation. Above it, there is no attempt to preserve separation.

    A gradual highlight roll-off spends some of the available output range on those differences instead. That necessarily changes values before they reach the ceiling.

    Clipping the brightness function also does not replace color conversion or correct HDR signal interpretation. An HDR picture cannot be made properly SDR just by deleting its HDR label and clipping encoded samples.

    If highlights become flat during Emby playback, clipping somewhere in the chain is one possible explanation, not proof that a setting named Clip is selected. The limit could occur in conversion, signal handling, or display processing. Once distinct values have actually been discarded, changing a later curve cannot recover them.
