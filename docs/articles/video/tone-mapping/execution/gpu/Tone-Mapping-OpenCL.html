    OpenCL Tone Mapping

    OpenCL is an interface for running parallel computations on supported devices. An OpenCL tone mapper divides picture processing into many small pieces that can run concurrently, commonly on a GPU.

    The word OpenCL tells you how the work is submitted, not which tone-mapping curve is used. A filter can offer several curves through the same OpenCL execution path. OpenCL itself also supports device types other than GPUs, so the selected device matters.

    Three pieces have to fit

    Piece Its role
    Application and filter Provide the tone-mapping code and supported input/output formats
    OpenCL runtime and driver Discover the device, compile or load its program, and submit work
    Device and frame access Supply the required capabilities and make the decoded pixels accessible

    A working hardware video decoder does not automatically establish that all three are available. Decoding and OpenCL compute are separate capabilities, even when they use the same physical GPU.

    FFmpeg 8.1's OpenCL filter provides a concrete example: it accepts specific hardware-frame formats, checks the source transfer characteristics, and launches an OpenCL tone-mapping kernel. Its accepted formats are implementation constraints, not universal limits of the OpenCL standard.

    That distinction is useful when reading an Emby transcoding log. Successfully selecting a decoder or encoder is only one part of the path. An OpenCL device initialization or filter-format error points to a different stage from a codec error. In a container, the application also needs access to the appropriate runtime and device; success on the host alone does not describe the application's environment.

    Once it runs, performance depends on more than the curve's arithmetic. Transferring frames between memory domains or incompatible processing stages can add overhead. Whether a particular Emby installation uses this path depends on the platform, bundled implementation, driver, and selected session; OpenCL support on the GPU alone is not a support guarantee.
