    Overview: Tone-mapping execution

    Tone-mapping execution locates brightness adaptation within the client or server pipeline and its available processing resources.

    The same adaptation goal can be carried out at different points in playback. A client can render for its own display, while a server conversion can produce a representation for the receiving app. CPU and GPU topics then explain the execution resources and data movement at the chosen point in that path.

    • Where tone mapping happens in an Emby playback session
      Tone mapping can occur during server transcoding or later in the player and display path, depending on the playback session.

    • CPU tone mapping
      CPU tone mapping performs the picture conversion on the general-purpose processor rather than running the mapping on a GPU.

    • GPU execution
      GPU tone mapping uses a supported compute or rendering interface to transform picture data within a media pipeline.
