    VP9 Video

    VP9 is a video coding format developed by the WebM Project. It is often encountered in web-origin video, including high-resolution content, but the codec is separate from its container.

    Compared with VP8, VP9 provides additional coding tools and supports higher sample depths in selected profiles. Its profile number is especially useful when one VP9 file plays directly and another needs a different path.

    VP9 profile Sample depth Color sampling
    0 8-bit 4:2:0
    1 8-bit 4:2:2 or 4:4:4
    2 10-bit or 12-bit 4:2:0
    3 10-bit or 12-bit 4:2:2 or 4:4:4

    Format permissions, not a claim that a particular device supports every combination.

    A decoder that handles Profile 0 may lack the required support for Profile 2. Even within Profile 2, do not infer 12-bit support from successful playback of a 10-bit stream. The selected decoder and its integration into the app determine the actual usable capabilities.

    Read HDR information separately

    A higher bit depth can help represent HDR pictures, but a VP9 profile alone does not identify HDR. Transfer characteristics, color information, and the display path still need to agree.

    In Emby, the source codec and profile describe the library file. If video transcoding is required, the delivered stream may use a different format. Repackaging without video conversion keeps the VP9 stream and its decoding requirements.

    The WebM Project links its bitstream description as a draft specification. Its published profile page and the implementation provide useful references; the draft's status should remain visible when using it as a technical source. There is no need to infer a universal bitrate or quality advantage from the codec name.
