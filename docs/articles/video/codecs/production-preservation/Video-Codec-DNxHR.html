    Avid DNxHR Video

    Avid DNxHR is the established name for resolution-independent production workflows in the VC-3 coding family. It extends the practical use of DNxHD-style picture coding to a wider range of picture sizes, including UHD and larger production rasters.

    The codec encodes pictures independently. Its quality levels serve different production purposes, from lightweight editing proxies to copies intended to retain more picture information.

    Familiar level Intended distinction
    LB Low-bandwidth production or proxy representation
    SQ Standard quality
    HQ High quality
    HQX High quality extended
    444 Higher-fidelity color representation

    Level names identify codec choices, not universal quality scores or direct-play guarantees. Their permitted sample formats depend on the codec generation and implementation.

    A level does not specify one fixed bitrate for every file. Picture size and frame rate matter, and Avid's newer unified DNx implementation also offers customizable rates. Consult the applicable mode's specification when estimating storage.

    Legacy labels remain useful

    Avid now calls the family Avid DNx, with the HD, HR, and GX suffixes removed from the newer naming scheme. The old DNxHR label remains relevant when inspecting existing files and older software exports. Historical mode restrictions should not be assumed to describe every capability of the newer codec.

    DNxHR is a lossy production codec. High quality and independence between pictures make it suitable for editing; neither property proves exact reconstruction of the original samples.

    For Emby, keep the production copy when creating a smaller playback version. A server input decoder and a receiving app's direct-play decoder are separate requirements. If video conversion is needed, start from the retained master and verify the actual delivered stream. A smaller derivative is a convenience copy, not a substitute for the source's preserved information.
