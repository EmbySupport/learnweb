    Default Track Flags

    A file's default audio flag is a hint about which track should be considered for automatic playback. It is not a command that every player must follow.

    The distinction matters when a film starts with a different soundtrack in two apps. Language preferences, accessibility choices, and remembered selections can affect the result as well as the file's flags.

    File property What it expresses
    Default audio flag Eligibility or preference for automatic selection
    Track language Which language the track represents
    Forced subtitle flag A subtitle selection hint for content such as foreign dialogue or signs
    Commentary or accessibility flags The track's intended service, where the format supports them

    The precise semantics depend on the container. In Matroska, more than one track can be eligible as default, including different languages. A player may override the default hint to meet user preferences.

    Default subtitles are not forced subtitles

    A default subtitle track might contain the full dialogue. A forced subtitle track commonly contains only the text needed alongside an otherwise understood soundtrack. Setting a forced flag on full subtitles can therefore produce an unwanted result.

    For an Emby selection problem, inspect the language and flags of the actual tracks, then compare the user's audio and subtitle preferences. A title containing the word “default” is merely text unless the relevant field is also set.

    Correcting these container fields usually does not require recompressing the picture or sound. It does require understanding the intended track: an English commentary track should not become the main soundtrack simply because its language matches the user.
