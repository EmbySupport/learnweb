    Track Language Metadata

    An audio track can contain English dialogue but appear as “Unknown” because its language field is missing or unhelpful. Software generally reads the tag; it does not establish the language by listening to the dialogue.

    Language metadata helps Emby identify choices and apply playback preferences. The same mechanism is useful for subtitles, but the language describes the subtitle text, which may differ from the soundtrack.

    Language value What it indicates
    eng English, using an ISO 639-2 code
    deu / ger German; terminology and bibliographic ISO codes
    pt-BR Portuguese with a Brazil region subtag in BCP 47
    und Undetermined language

    Containers differ in the code systems they use. Matroska includes a legacy language field and a BCP 47 field; when both are present, the BCP 47 field takes precedence under its specification.

    A track title is another field

    “English 5.1” in a title is useful for a person, but it is not the same as a machine-readable English language tag. Likewise, setting the language to English does not identify a track as commentary or mark its subtitles as forced.

    If the wrong language is chosen, check the file's actual fields alongside the user's preferences. Correcting a container language tag can often be done without re-encoding the audio or video.

    The movie's original language in library metadata is a separate property. It describes the work, while track language describes one particular audio or subtitle component. A multilingual film can legitimately contain several differently tagged tracks.
