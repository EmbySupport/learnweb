    CUE Sheets

    A CUE sheet can describe several songs inside one long audio file. It records where tracks begin and can provide titles, performers, and disc-oriented information. The sound stays in the referenced file.

    FILE "Concert.wav" WAVE
  TRACK 01 AUDIO
    TITLE "Opening"
    INDEX 01 00:00:00
  TRACK 02 AUDIO
    TITLE "Second song"
    INDEX 01 04:30:00

    Illustrative two-track description of one recording.

    The final number in a CUE timestamp is not milliseconds. Its format is minutes:seconds:frames, using 75 CD frames per second.

    CUE timestamp Position
    00:00:00 Start of the referenced file
    04:30:00 4 minutes, 30 seconds
    04:30:30 4 minutes, 30.4 seconds

    Boundaries are not separate soundtracks

    INDEX 01 marks a track's main start. A CUE sheet can also describe pregaps and other indexes, so a more elaborate file may express disc layout beyond a simple song list.

    This “track” is a region of an audio recording, unlike a separately selectable audio track in a movie container. The distinction helps when organizing a concert or album for an Emby music library.

    A CUE sheet does not physically split or convert the referenced sound. For software that does not interpret the sheet, the audio remains one long file. An export into separate songs needs to use the boundaries and preserve the appropriate metadata.

    Changing the audio filename without updating the FILE reference can break that connection. Changing the recording's timing can make the boundaries inaccurate even though the text file still parses.
