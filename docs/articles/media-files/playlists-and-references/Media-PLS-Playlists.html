    PLS Playlists

    A PLS file is a playlist written as key/value pairs. It is often encountered when a radio station provides a small download that opens its stream in a media player.

    A simple version looks like this:

    [playlist]
File1=Music/Opening.mp3
Title1=Opening song
Length1=180
File2=Music/Second.mp3
Title2=Second song
Length2=240
NumberOfEntries=2
Version=2

    The matching numbers associate each location with its title and duration. Length values are conventionally seconds; a value of -1 is commonly used when the duration is unknown, as with a live stream.

    The playlist is not the recording

    The PLS file can be tiny because it stores only references and descriptions. Downloading it does not save the radio audio for offline playback.

    If a referenced URL changes or a relative file moves, the entry can stop working while the playlist remains readable. Inspect the FileN values rather than treating the displayed title as the source address.

    For an Emby user collecting media references, distinguish this playlist syntax from STRM pointer files and from the M3U channel lists used by Live TV. They may all point to media, but their readers expect different text structures.

    There is no universal rule that renaming a PLS file to another playlist extension converts it. Conversion needs to preserve the media locations in the destination syntax. Player-specific handling can also affect which optional fields are used.
