    M4A and M4B File Conventions

    M4A and M4B are audio-oriented filename conventions for MP4-family files, with M4B commonly indicating audiobook content.

    A music album and a spoken book can use the same MP4-family audio structure. M4A commonly identifies audio such as music; M4B commonly identifies a book-oriented use, often with chapters.

    The file still needs a coded audio track. An M4A can contain AAC or Apple Lossless, so the extension does not prescribe one audio representation.

    Layer in an audiobook experience Information involved
    Encoded sound Audio codec, sample rate, channels, and timing
    Book navigation Chapter names and positions
    Library description Book, author, cover, and organization
    Listening history The user's position in a particular item

    Chapter markers and a resume position at 37:12

    An uninterrupted book track can carry a chapter list without being split into separate sound files. A chapter at 30:00 names a position within that track. If a listener stops at 37:12, the playback/library system can retain 2,232 seconds as that user's position.

    On resuming, the system requests the corresponding source time. The container's sample navigation gets it to the encoded data. Chapter descriptions can supply names near that point, while the user's remembered position supplies the specific resume request. These are different records used together.

    Changing .m4a to .m4b changes a filename convention; it does not add the chapter list or populate listening history. A particular app may use the convention to classify the item, but the underlying data still has to exist.

    Preserve the right book information in a conversion

    MP4/QuickTime supports different chapter representations. A converter that retains the sound may omit the chapter representation another reader expects. Compare chapter names and exact positions alongside decoded sound and duration.

    If an introduction is removed, later chapter positions and any retained listening position need interpretation against the edited timeline. An audio-preserving remux with unchanged timing is a different operation from such an edit.

    For Emby, audiobook organization supplies the library context for this book experience. The file's track and chapters describe the recording; the item's metadata and playback records describe how it is presented and used.
