    AAC: Low Overhead Audio Transport Multiplex (LATM)

    A broadcast recording may report AAC with LATM rather than the familiar ADTS packaging. That extra name identifies an input structure the player must understand before it can decode the sound.

    Low Overhead Audio Transport Multiplex (LATM) carries MPEG-4 audio data with multiplex and configuration information. Configuration can be supplied in-band and reused, avoiding the need to repeat a full independent description around every audio unit.

    Layer Its job
    AAC coding tools Represent the compressed sound
    LATM Organize audio payloads and the information needed to interpret them
    LOAS, when used Add synchronization and length framing around LATM data
    Outer delivery, such as TS or RTP Carry the packaged audio to the receiver

    LOAS, Low Overhead Audio Stream, is a related framing layer, not a synonym for the multiplex itself. RFC 6416 also defines carriage of LATM audio elements in RTP, illustrating why LATM need not always arrive with the same outer wrapper.

    The receiver needs both parsing and decoding

    A device can support an AAC variant yet lack the input path for LATM in a particular container. Conversely, recognizing LATM does not establish support for every MPEG-4 audio coding tool its configuration can describe.

    For an Emby recording with sound problems, inspect the transport and the audio profile together. A successful probe on the server does not by itself establish that the selected app can consume the original packaging directly. The delivered stream and its handling on that platform matter.

    Changing LATM to ADTS or MP4 is not a filename operation. A converter must interpret the configuration and translate the framing, and some combinations may need more than a simple header rewrite.

    Retain the original when investigating such a conversion. Check channel layout, output sample rate, timing, and playback through the affected programme transition, where a fresh configuration can become important.
