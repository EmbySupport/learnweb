    DVD-Video File Structure

    A DVD-Video folder is a presentation made from several related files, rather than a directory of independent movies. Its VIDEO_TS structure keeps encoded media and the navigation needed to interpret it.

    The filesystem and the DVD-Video application rules are different layers. A correctly copied directory preserves file relationships; the player still needs to interpret the disc's title and navigation information.

    File type in VIDEO_TS Role
    .VOB Video objects containing multiplexed picture, sound, subtitles, and navigation data
    .IFO Descriptions of title sets, programme chains, chapters, and playback choices
    .BUP Backup copies of IFO information

    A title's media is often split across numbered VOB files. Those boundaries are storage divisions, not necessarily chapter or scene boundaries.

    Follow the title, not just the filenames

    DVD navigation can select and order cells within the video objects. Menus, alternative angles, or different cuts can make the intended sequence more complicated than playing every VOB in directory order.

    An isolated VOB uses program-stream packaging and may open in a general media reader. That does not establish that it represents the complete feature or follows the same path as a DVD-aware reader.

    For a collection used with Emby, distinguish a complete DVD folder or image from a single movie file. Disc navigation support and the available playback path depend on the app and platform; follow the movie organization guidance for the library layout.

    If creating one self-contained movie from a disc presentation, choose the intended title and verify its full sequence, selected audio, subtitles, and chapters. Repackaging its encoded streams can avoid recompression, but it still requires resolving the disc structure correctly. The largest file or the first numbered title is only a clue, not proof of the main feature.
