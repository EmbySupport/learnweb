    Digital Media Data Units

    A lower-case b usually means a bit; an upper-case B means a byte. One byte contains eight bits. That small typographic difference explains why a 100 Mb/s connection does not copy files at 100 MB/s.

    Before overhead, 100 Mb/s corresponds to 12.5 MB/s.

    Unit Amount
    1 MB, megabyte 1,000,000 bytes
    1 MiB, mebibyte 1,048,576 bytes
    1 GB, gigabyte 1,000,000,000 bytes
    1 GiB, gibibyte 1,073,741,824 bytes

    Mega and giga are decimal prefixes. Mebi and gibi explicitly identify binary multiples. The prefixes apply to bits too: Mb and Mib differ for the same reason.

    Why two size displays disagree

    A file containing one billion bytes is 1 GB or about 0.931 GiB. Both numbers describe the same file. Some software uses binary calculations while displaying a decimal-looking label, so check the program's convention before concluding that space or data is missing.

    For an Emby streaming estimate, use consistent units: a media rate of 8 Mb/s is about 1 MB per second, or 60 MB per minute. File-copy figures, connection speeds, and media bitrates become directly comparable only after conversion.

    The storage occupied on a disk can also differ from the exact file length because allocation happens in blocks. That is a filesystem effect, separate from the decimal-versus-binary distinction.
