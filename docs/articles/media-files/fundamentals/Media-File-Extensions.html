    Media File Extensions

    A media file extension is a naming convention that hints at the file's format without proving its contents.

    A file extension is the part of a name after its final dot. It helps software choose an application or decide which files to examine. Some endings describe containers, while others conventionally identify one audio coding family.

    Filename Usual interpretation
    Movie.mkv Matroska video container
    Recording.mov QuickTime container
    Song.mp3 MPEG Layer III audio file
    Movie.strm A text pointer to another media source

    Consider a downloaded film named Movie.mp4. Changing that name to Movie.mkv alters the directory entry; its internal headers and media bytes stay the same. A real container conversion reads those bytes and writes new packaging. The two operations affect different parts of the stored item.

    If the ending disagrees with inspection, use the detected format to establish what the file actually is. Some readers examine its signature and open it despite the name; filename-based discovery can make a different choice.

    A second naming issue arises when extensions are hidden. A text editor may save Movie.strm.txt while the file browser displays Movie.strm. The full filename reveals why it is treated as ordinary text rather than a media pointer. Reading the internal format and viewing the full name resolve different kinds of naming mistake.
