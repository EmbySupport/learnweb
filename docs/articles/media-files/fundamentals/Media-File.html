    What Is a Media File?

    A movie file is more than a row of pictures. It usually contains compressed video, one or more soundtracks, timing information, and descriptions that tell a player how those pieces fit together. Subtitles and chapter markers may be included too.

    Most of that is organized by a container. The codecs describe how the picture and sound data are represented. A file can use a familiar container while carrying a codec that a particular player cannot decode.

    What Emby needs to find out

    When Emby examines a file, the useful questions include which streams exist, their formats, and how long they run. Those details help describe the item and determine how to deliver it to an app. The filename alone cannot answer them.

    The information also has two different purposes. Technical metadata such as resolution and audio language helps playback. A library title, synopsis, or poster describes the work. A movie can have correct library information while its underlying file has an incorrect language tag or damaged timestamps.

    For a playback question, begin with the file's media information and the selected audio and subtitle tracks. “It is an MKV” describes its packaging; it does not yet describe what the app must play.
