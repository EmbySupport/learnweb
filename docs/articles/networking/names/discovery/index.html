    Overview: Service discovery

    Service discovery exchanges information about available destinations within each protocol's defined scope.

    mDNS, SSDP and Emby's discovery mechanism use different messages and relationships. Their results help locate a service; they do not replace the connection or access checks needed to use it. This group explains why discovery can work on one network segment and produce a different result across a boundary.

    • Multicast DNS (mDNS)
      Multicast DNS resolves specified names on a local link through participating responders, with DNS-based service discovery adding service-instance and endpoint information.

    • SSDP discovery
      SSDP discovers UPnP candidates through advertisements and searches, returning service-description locations whose later accessibility must be evaluated separately.

    • Emby server discovery
      Emby’s documented local discovery exchange uses a UDP broadcast to find server identity and an advertised address, followed by a separate application connection.
