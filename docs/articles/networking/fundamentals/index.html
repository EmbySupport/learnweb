    Overview: Home network fundamentals

    Home-network fundamentals connect addressing and transport with the local or remote route a media request uses.

    A connection needs a destination address, a usable path and an appropriate transport endpoint. Local and remote requests can meet different conditions along that path. The addressing and transport branches establish those layers before discovery, router rules or streaming performance are investigated.

    • How a home media network works
      A home media network carries requests and media between Emby Server and client apps through local links and any routed boundaries in their selected path.

    • Local and remote connections
      Local and remote connections describe the path and client-address context used to reach Emby, which can differ from a device’s physical location or the hostname it uses.

    • IP addressing
      IP addressing identifies interfaces and network relationships under particular address scopes and configuration rules.

    • Transport protocols and ports
      Transport protocols and ports identify how applications exchange data and which endpoint receives it.
