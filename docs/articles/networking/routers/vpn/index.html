    Overview: VPN routing

    VPN access and routing place media connections within a selected tunnel and its surrounding network paths.

    A tunnel can provide a route to a private server, but the traffic still follows the configured routing decisions. Split tunneling determines which destinations use that route and which use another path. The pages here trace which destinations use the tunnel and which follow another route.

    • VPN access to a media server
      VPN access adds a tunnel path into a network, while destination routes, return routes, name resolution and service policy determine whether a media server is usable through it.

    • VPN routing and split tunneling
      VPN routing determines which destination prefixes use a tunnel, with route specificity, overlapping address realms and DNS policy separate from the tunnel’s connected state.
