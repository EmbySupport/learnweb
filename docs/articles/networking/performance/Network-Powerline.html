    Powerline networking and a variable shared channel

    Powerline networking carries data over electrical wiring through a shared channel whose usable rate depends on the supported PHY/link family and changing path conditions.

    Powerline adapters can carry network traffic over a building’s electrical wiring. To the attached Ethernet devices, a pair can provide another link in the server path.

    The electrical communication channel has its own modulation, error handling and shared-resource behavior.

    The label describes a PHY family and capability

    The cited G.hn references describe wireline home-network PHY and data-link roles. Other powerline families have their own protocols; a generic “powerline” label does not establish interoperability.

    Advertised or observed property What it describes
    Maximum PHY capability A supported physical operation under its defined conditions
    Current link indication The device’s present interpreted link state/rate
    Useful transferred media bytes Application delivery over the actual path
    Ethernet socket rate Another attached link’s negotiated capability

    Those quantities should be kept separate. A fast Ethernet socket does not remove a slower electrical segment.

    The electrical path can vary

    Wiring layout, coupling, connected loads and interference can change the available channel. Signal processing can alter its usable carriers/coding and retry behavior.

    A nearby wall socket is not necessarily the same communication path as another nearby socket. The actual supported adapter and electrical arrangement determine the result.

    A long average can hide short service changes

    Use this original reduced payload service:

    {
  "intervalSeconds": 4,
  "availableMbitPerSecond": [60, 30]
}

    Equal four-second intervals average forty-five Mbit/s. A fifty-Mbit/s media demand still exceeds both that average and the second interval’s available service.

    A lower demand can fit the average yet need buffer tolerance during a dip. The time trace and usable-media reserve determine that relationship.

    This exercise is not a claimed powerline benchmark or a conversion from an advertised adapter number.

    Measure its place in the complete route

    Compare a transfer over the intended adapter path with an appropriate reference path using the same sender, receiver and direction.

    That separates the electrical segment’s effect from server preparation, remote upload capacity or receiver performance. Streaming-path measurements develops those observation boundaries.
