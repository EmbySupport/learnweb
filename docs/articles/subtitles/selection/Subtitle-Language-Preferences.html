    Subtitle language preferences

    Subtitle language preferences guide selection through language identifiers, script/region distinctions and the subtitle content role required for viewing.

    A subtitle language preference tells a player which language the viewer wants to read. It does not determine whether that track contains all dialogue, accessibility captions or just selected passages.

    The player needs language identity and the intended content role.

    Language identifiers can be more specific than a name

    BCP 47 language tags can express language, script and region. For example:

    Tag Meaning
    en English
    en-GB English with a United Kingdom regional distinction
    zh-Hans Chinese using Simplified script
    zh-Hant Chinese using Traditional script

    Script and region are different subtags. A regional label can be associated with a customary script in a library convention, but it is not identical to an explicit script declaration.

    Containers and naming systems can use other representations, including ISO 639 codes or supported language names. A matching system needs to interpret those schemes rather than compare arbitrary display strings.

    Emby's external naming documentation describes supported language identification in filenames. The format's cue text remains a separate property from that label.

    Language matching does not resolve the role

    Suppose a viewer prefers English and sees these candidates:

    Candidate Language match Remaining question
    English dialogue Yes Is dialogue-only content sufficient?
    English SDH Yes Are sound/speaker descriptions desired?
    English forced passages Yes Should only the required selected passages appear?
    Spanish full dialogue No Is another language being explicitly selected?

    A hearing-impaired preference may distinguish the first two. A forced-only mode can distinguish a sparse required-passage track from a full translation. The selected audio language can also be relevant to a policy that decides when translation is needed.

    A track title is a useful clue, but incorrect metadata can make the choice disagree with the actual text. Inspecting its contents establishes what the resource supplies.

    The current viewing choice can override a general preference

    A viewer can explicitly choose another language for one film. A player can remember that selection. Changing a preferred language and choosing a specific track are different operations with different scope.

    Emby's preference documentation is the appropriate source for its selection controls. For a surprising result, compare the active choice, remembered selection, language identifiers and role metadata before assuming that the language decoder is broken.
