    Overview: Capability exchange

    Capability exchange describes the signal formats a receiving path reports and the metadata used to interpret them.

    EDID and CTA capability blocks supply structured information about a display path. HDR signaling then identifies properties of the transmitted picture. These pages distinguish a reported capability from the signal currently in use, especially when an intermediate receiver participates.

    • EDID
      EDID is a structured display-capability declaration that a source reads to learn supported timings and related properties, potentially through an intermediate device.

    • CTA-861 capability blocks
      CTA-861 capability structures extend display declarations with defined video, audio, color and metadata information used by consumer digital-interface routes.

    • HDMI HDR signaling
      HDMI HDR signaling communicates relevant interpretation of the active output picture, separately from HDR metadata in the source and HDR capabilities declared by the sink.
