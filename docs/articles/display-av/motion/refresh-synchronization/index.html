    Overview: Refresh and synchronization

    Refresh and synchronization connect frame presentation to a display's update schedule.

    The source cadence and the screen's refresh schedule must form a presentation arrangement. Frame-rate matching, VSync and VRR address different parts of that relationship. Their pages explain the timing decision, including what varies and what remains fixed in the selected mode.

    • Display refresh rate
      Display refresh rate describes how often the output refreshes or scans pictures, independently of how often the source contains a new picture.

    • Frame-rate matching
      Frame-rate matching selects a display timing compatible with the source cadence so source pictures can receive regular presentation durations.

    • Vertical synchronization (VSync)
      Vertical synchronization coordinates presentation with display refresh boundaries to avoid showing incompatible picture updates within a scan.

    • Variable refresh rate (VRR)
      Variable refresh rate allows a supported display route to vary presentation intervals within a defined operating range.
