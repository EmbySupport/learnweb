    Overview: Storage hardware and connections

    Storage hardware and connections describe the medium, command interface and path supplying file data.

    An SSD names a medium, SATA or NVMe names an interface arrangement, and USB or network attachment adds another part of the path. HDD behavior contributes mechanical positioning and rotation. These pages keep those layers separate so a large interface-rate label does not stand in for the observed workload.

    • Hard disk drives
      A hard disk drive reads magnetic platters through moving heads, so positioning and rotation influence small and mixed workloads.

    • Solid-state drives
      A solid-state drive accesses flash through a controller that manages physical pages, erased blocks, spare space and write endurance.

    • SATA storage
      SATA connects storage devices through a negotiated serial interface whose link rate is separate from useful file throughput.

    • NVMe storage
      NVMe defines storage commands and queues, commonly carried over PCIe for local SSDs, while slot wiring and workload determine usable performance.

    • USB-attached storage
      USB-attached storage adds a negotiated host connection and enclosure bridge between the server and the physical drive.

    • Network-attached storage (NAS)
      A NAS serves files over a network, so media access depends on its disks, sharing protocol, access policy and connection to the Emby server.
