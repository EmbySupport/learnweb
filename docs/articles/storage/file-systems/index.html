    Overview: File systems and paths

    File systems connect names and stored data through allocation, limits, access rules and activity mechanisms.

    A path identifies a file through a particular filesystem and its current view. Format limits, links and mounted trees influence that lookup, while timestamps, locks and notifications describe activity around the file. The branches here follow those relationships from stored capacity to a server's actual observation.

    • File systems
      A file system turns storage space into named files and directories, with allocation, metadata and access rules defined by its format and implementation.

    • File size limits
      A file-size limit restricts one file independently of the volume's total free space, which matters for long recordings and high-bitrate media.

    • Path names and links
      Path names and links determine how a process resolves a visible location to a particular file or mounted tree.

    • File activity and notifications
      File activity mechanisms report time, coordinate concurrent access and notify applications of observed changes.
