    Overview: Image presentation

    Image presentation turns stored picture data into a sized, color-interpreted and sometimes animated or HDR display result.

    A thumbnail is a derived picture, while a color profile supplies interpretation for the picture's samples. Animation and HDR still images add further presentation relationships. This branch separates those operations, helping explain a changed appearance without assuming that the source pixels themselves were rewritten.

    • Image resizing
      Image resizing reconstructs a source image onto a new sample grid, with fit/crop policy, filtering, colour domain and alpha handling affecting the result.

    • Image thumbnail generation
      Thumbnail generation creates a smaller viewing derivative from a selected, oriented and interpreted source image, with cache identity determining when that derivative remains valid.

    • ICC color profiles
      An ICC profile describes a colour relationship used by a colour-management process to interpret source samples and prepare values for a destination.

    • Animated images
      An animated image changes a shared canvas through timed frame data and composition/disposal rules, rather than necessarily storing independent full-size pictures.

    • HDR still images
      An HDR still presentation combines suitable image samples and luminance/colour interpretation with an output path that can render the intended brightness range or a defined fallback.
