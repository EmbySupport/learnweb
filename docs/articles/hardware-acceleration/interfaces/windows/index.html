    Overview: Windows

    Windows video interfaces connect applications to supported decoding, processing or transform operations.

    DXVA2 and D3D11 video acceleration describe particular routes to video work. Media Foundation transforms provide another operation and negotiation model. The pages here explain those interfaces so an API name, a device capability and a negotiated media type remain distinguishable.

    • DirectX Video Acceleration (DXVA2)
      DXVA2 exposes Windows video-acceleration services through which a software media implementation submits supported decoding or processing work to a driver-backed device.

    • Direct3D 11 video acceleration (D3D11VA)
      Direct3D 11 video acceleration uses driver-backed video interfaces and texture resources to reconstruct supported encoded pictures and connect them to compatible consumers.

    • Media Foundation transforms
      A Media Foundation transform is a Windows media-processing component whose negotiated types, input/output state and resource context determine its decoding, encoding or processing role.
