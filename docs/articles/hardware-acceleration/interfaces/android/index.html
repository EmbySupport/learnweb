    Overview: Android and embedded systems

    Android and embedded media interfaces expose platform-specific codec and processing relationships.

    MediaCodec, OpenMAX IL and Rockchip's MPP describe different software routes to media work. Their buffer and lifecycle contracts matter alongside the hardware's coding capabilities. These pages provide that interface context for an application running on the corresponding platform.

    • Android MediaCodec
      MediaCodec exposes Android codec components through configured input/output buffers or surfaces whose ownership, timing and state determine how media is processed.

    • OpenMAX IL
      OpenMAX IL defines a multimedia component interface whose ports, buffer exchanges and asynchronous state transitions coordinate supported processing implementations.

    • Rockchip Media Process Platform (RKMPP)
      Rockchip MPP connects supported codec implementations, buffer management and hardware abstraction to a compatible Rockchip platform and kernel interface.
