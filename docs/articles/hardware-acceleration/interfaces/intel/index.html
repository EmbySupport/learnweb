    Overview: Intel

    Intel media interfaces connect video engines and processing facilities to supported application operations.

    Quick Sync identifies a media-acceleration technology, while VPL and the legacy Media SDK describe software relationships to supported hardware. VPP adds video-processing operations to that picture. These topics locate the names in the pipeline so decode, processing and encode support can be discussed separately.

    • Intel Quick Sync Video (QSV)
      Intel Quick Sync Video is the name for Intel’s dedicated media-acceleration capabilities, reached through supported software and driver paths for decoding, processing and encoding.

    • Intel VPL and oneVPL
      Intel VPL is the media library interface and dispatcher used to select supported Intel video implementations and coordinate decode, encode and processing sessions.

    • Intel Media SDK (legacy)
      Intel Media SDK is a discontinued media software interface whose names remain in older Intel acceleration stacks and logs, distinct from the hardware generations those stacks use.

    • Intel video processing (VPP)
      Intel VPP processes decoded pictures into a requested output picture configuration, coordinating supported transformations, output cadence and surface completion.
