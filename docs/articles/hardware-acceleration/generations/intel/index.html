    Overview: Intel media-engine generations

    Intel generation pages describe the media capabilities associated with particular processor or graphics-engine families.

    Kaby Lake, Xe-LP, Arc and the other families below belong to different hardware contexts. Their pages retain the relevant decode, encode and processing scope rather than ranking devices from one broad generation label. The general support-matrix topic supplies the vocabulary for comparing those capabilities.

    • Intel Kaby Lake media capabilities
      Kaby Lake’s media capabilities provide important AVC and ten-bit HEVC decoding paths, with encoding classifications and exposed features dependent on the documented software implementation.

    • Intel Elkhart Lake and Jasper Lake media capabilities
      Elkhart Lake and Jasper Lake expose a documented low-power Intel media feature set whose AVC, HEVC and VP9 operations differ from newer AV1-capable implementation columns.

    • Intel Xe-LP media capabilities
      Xe-LP-era Intel media paths include AV1 decoding in the documented full-feature implementation, while AV1 encoding belongs to later specified media groups.

    • Intel Arc Alchemist media capabilities
      Arc Alchemist’s documented media implementation adds AV1 encoding alongside supported decoding, with source/target formats and driver build determining the usable route.

    • Intel Xe-LPG media capabilities: Meteor Lake and Arrow Lake
      Meteor Lake and Arrow Lake use the documented MTLx media implementation group, whose AV1 and encoding-interface declarations need to be interpreted at their own format and software scope.

    • Intel Xe2 media capabilities: Lunar Lake and Battlemage
      Lunar Lake and Battlemage have separate Intel driver columns whose format/direction declarations include AV1 and differ from earlier groups in selected HEVC and VP9 rows.
